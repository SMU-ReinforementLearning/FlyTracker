# 01 그림 지침

> `01-camera-markov-process.md`에 들어갈 그림 스무 장을 만드는 사람이나 AI에게 주는 지침입니다. 본문을 읽지 않아도 그릴 수 있게 필요한 정의와 값을 모두 적었습니다.

## 1. 요청

그림은 스무 장입니다. 이미 있는 열네 장 가운데 아홉 장은 그대로 쓰고, 다섯 장은 없애고, 열한 장을 새로 그립니다. 새로 그리는 그림은 이미 있는 그림의 색, 글꼴, 선 굵기, 범례 형식을 그대로 물려받습니다.

새 그림 열한 장 가운데 아홉 장은 시간선 그림입니다. 가로에 시간을 두고 카메라의 운동을 선으로 그리는 그림입니다. 이전 판에서는 이 그림을 금지했는데, 그 금지를 거둡니다. 그림의 설명 문장은 본문에 이미 있으므로 그림 안에는 넣지 않습니다.

## 2. 배경

방 안의 한 점 $p_0$에 고정된 카메라가 좌우(yaw)와 위아래(pitch)로만 돕니다. 방향 $s$에서 화면에 들어오는 방 안의 공간이 $\mathrm{View}(s)$이고, 이것 하나하나를 state라 합니다. state는 방향과 하나씩 대응하므로 그 방향 $s=(s_{\mathrm{yaw}},s_{\mathrm{pitch}})$로 적습니다. $s_{\mathrm{yaw}}$는 $360^\circ$마다 되돌아오므로 state 전체 $\mathcal S$는 원통의 옆면입니다.

카메라의 운동은 하나로 정해져 있지 않습니다. 가능한 운동 전체를 $\Omega$로 적습니다. 시각 $t$의 state가 $\mathcal S$의 부분집합 $F$ 안에 있는 운동들을 $S_t^{-1}(F)$로 적습니다. $F$에서 $S_t^{-1}(F)$로 가는 이 대응이 시각 $t$의 state $S_t$입니다.

지금 $F$ 안에 있을 때 $u$초 뒤에 놓일 수 있는 state 전체를 $T_u(F)$로 적습니다. state $s$에서 $u$초 뒤에 $s'$에 놓일 수 있으면 화살표 $s\xrightarrow{\,u\,}s'$로 적습니다. 화살표는 이어 붙일 수 있습니다. $s\xrightarrow{\,t\,}s'$이고 $s'\xrightarrow{\,u\,}s''$이면 $s\xrightarrow{\,t+u\,}s''$입니다.

### 3.4 금지

state space에 격자선을 그리지 않습니다. 그림 안에 문장을 쓰지 않고 라벨은 기호나 명사구로 씁니다. 이 지침에 없는 것(policy, 보상, 각속도, 초파리)을 넣지 않습니다. 그림자, 그라데이션, 입체 장식을 쓰지 않습니다. 라벨이 도형이나 다른 라벨과 겹치면 지시선을 써서 바깥으로 뺍니다.

## 4. 그림용 값

아래 값은 그림을 그리려고 고른 예시 값입니다. 모델이 정한 값이 아닙니다.

### 4.1 방과 카메라

방은 한 변이 4인 정육면체입니다. 좌표는 $x$(동), $y$(북), $z$(위)이고 범위는 모두 0에서 4입니다. 카메라의 자리는 $p_0=(2,2,1)$입니다. 화면의 가로 시야각은 60°, 세로 시야각은 45°입니다. yaw는 북쪽($+y$)이 0°이고 위에서 볼 때 시계 방향으로 커집니다. pitch는 수평이 0°이고 위쪽이 양수이며, 범위는 −60°에서 60°입니다.

### 4.2 두 Example

각의 단위는 도, 시간의 단위는 초이고, $s_{\mathrm{yaw}}$는 360으로 나눈 나머지로 읽습니다. 두 Example 모두 $s$에서 나가는 화살표가 하나입니다.

Example 1의 화살표는 다음과 같습니다.

$$s\xrightarrow{\,u\,}\big(s_{\mathrm{yaw}}+30u,\ s_{\mathrm{pitch}}\big)$$

Example 2의 화살표는 다음과 같습니다. $a=20$입니다.

$$s\xrightarrow{\,u\,}\big(s_{\mathrm{yaw}}+30u,\ 20+e^{-0.5u}(s_{\mathrm{pitch}}-20)\big)$$

### 4.3 검산 값

Example 2의 값입니다. 스크립트의 계산이 이 값과 0.1 안에서 맞아야 합니다.

|---|---|---|
| $(40^\circ,\,-50^\circ)$ | 1초 | $(70^\circ,\,-22.5^\circ)$ |
| $(40^\circ,\,-50^\circ)$ | 2초 | $(100^\circ,\,-5.8^\circ)$ |
| $(100^\circ,\,-5.8^\circ)$ | 3초 | $(190^\circ,\,14.3^\circ)$ |
| $(40^\circ,\,-50^\circ)$ | 5초 | $(190^\circ,\,14.3^\circ)$ |
| $(30^\circ,\,-50^\circ)$ | 1.5초 | $(75^\circ,\,-13.1^\circ)$ |
| $(70^\circ,\,-20^\circ)$ | 1.5초 | $(115^\circ,\,1.1^\circ)$ |

### 그림 5. 운동과 시각 t의 state

시간선 그림이고 높이는 280입니다. 세로선은 둘입니다. 가로 130이 시각 $0$, 가로 470이 시각 $t$이고, 이 그림에서만 두 세로선을 실선으로 그립니다. 운동 셋은 모두 회색입니다.

```
M130 70  C 240 60,  340 120, 470 90
M130 140 C 240 170, 340 120, 470 160
M130 215 C 240 230, 340 190, 470 225
```

시작점 셋에는 작은 회색 점을, 끝점 셋에는 강조색 점을 찍습니다. 시작점 왼쪽에 "운동 1", "운동 2", "운동 3"을, 끝점 오른쪽에 $s$, $s'$, $s''$을 붙입니다. 시각 $t$의 세로선 위쪽 끝에 $\mathcal S$를 붙입니다. 범례는 두지 않습니다.

### 그림 6. 운동과 진리집합

시간선 그림이고 높이는 300입니다. 세로선은 가로 130(시각 $0$)과 가로 470(시각 $t$)입니다. 문 $F$는 가로 470의 세로 70에서 160까지입니다. 운동 넷 가운데 위의 둘은 문을 지나므로 강조하고, 아래 둘은 회색입니다.

```
M130 70  C 240 60,  340 110, 470 90
M130 120 C 240 150, 340 110, 470 140
M130 175 C 240 190, 340 170, 470 195
M130 225 C 240 235, 340 215, 470 232
```

시작점 왼쪽에 "운동 1"부터 "운동 4"를 붙이고, 문 오른쪽에 $F$를, 시각 $t$의 세로선 위쪽 끝에 $\mathcal S$를 붙입니다. 범례는 강조색 선에 "명제가 참인 운동", 회색 선에 "명제가 거짓인 운동"입니다.

### 그림 7. 운동에서 state로

시간선 그림이 아닙니다. 옛 그림 7(새 그림 9)의 둥근 사각형 둘을 그대로 쓰고, 왼쪽에 $\Omega$, 오른쪽에 $\mathcal S$를 붙입니다. 왼쪽 안에 점 넷을 세로로 놓고 "운동 1"부터 "운동 4"를 붙입니다. 오른쪽 안에 점 셋을 세로로 놓고 $s$, $s'$, $s''$을 붙입니다.

가는 회색 화살표 넷을 그립니다. 운동 1과 운동 2는 $s$로, 운동 3은 $s'$으로, 운동 4는 $s''$으로 갑니다. 오른쪽에서 $s$와 $s'$을 둘러싼 영역을 강조색 바탕으로 칠하고 $F$를 붙입니다. 왼쪽에서 운동 1, 2, 3을 둘러싼 영역을 같은 바탕으로 칠하고 라벨은 붙이지 않습니다. 범례는 강조색 바탕 표본에 "진리집합" 하나입니다.

### 그림 8. 같은 state, 다른 그 뒤

시간선 그림이고 높이는 280입니다. 세로선은 가로 300(시각 $t$)과 가로 480(시각 $t+u$)입니다. 문 $F$는 가로 480의 세로 62에서 118까지입니다. 두 운동은 (300, 140)에서 만났다가 갈라집니다. 첫째는 강조색이고, 둘째는 회색이되 투명도를 주지 않습니다.
