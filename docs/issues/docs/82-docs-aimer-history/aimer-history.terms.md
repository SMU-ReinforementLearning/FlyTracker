# 조준기 변천사 용어표

`aimer-history.md`를 쓰기 전에 정한 표기다. `ui-text.glossary.md`에 있는 표기는 그대로 가져왔다.

| 표기 | 뜻 | 쓰지 않을 말 | 정의 위치 |
|---|---|---|---|
| 조준기 | 방 안의 초파리를 겨누는 장치이고, 강화학습으로 학습하는 대상이다 | 포탑, 터렛, 에이머 | 개요 |
| 포획 | 조준기가 초파리를 잡아 에피소드가 끝나는 것이다 | 캡처 | 개요 |
| 환경 버전 | 관측, 행동, 보상, 포획 조건처럼 학습한 모델이 기대는 가정이 바뀔 때마다 올리는 번호다 | env 버전 | 개요 |
| 화면 좌표 | 조준기의 카메라 화면 안에서 초파리가 있는 자리다 | | 조준기와 초파리 |
| 탐색 | 안 보이는 초파리를 찾는 동작이다 | 수색, 탐색 잡음 | 조준기와 초파리 |
| 추적 | 보이는 초파리에 조준 방향을 맞추고 따라가는 동작이다 | 트래킹 | 조준기와 초파리 |
| 기준선 | 사람이 짠 규칙으로 움직이는 조준기다 | 베이스라인, 룰 기반 | 개요 |
| 조준기 agent | 강화학습으로 학습하는 조준기다 | RL 조준기, SAC 혼자 | 조준기와 초파리 |
| 모델 | 학습을 마친 조준기 agent 하나다 | | 조준기와 초파리 |
| 규칙 초파리 | 사람이 짠 규칙으로 피하는 초파리다 | 룰 초파리, 기본 초파리 | 조준기와 초파리 |
| 각도 조건 | 조준 오차가 3° 안인 상태가 0.2초 이어지면 포획인 조건이다 | 3° 조건 | 에피소드와 포획 조건 |
| 조준 오차 | 조준 방향과 초파리 방향 사이의 각도다 | 각도 오차 | 에피소드와 포획 조건 |
| 레이저 조건 | 빔까지 거리가 1.25mm 안인 상태가 0.15초 이어지면 포획인 조건이다 | 레이저 명중 | 에피소드와 포획 조건 |
| 빔까지 거리 | 초파리 몸 중심에서 레이저 빔 중심선까지의 거리다 | 빔 오차, 레이저 거리 | 에피소드와 포획 조건 |
| 포획 시간 | 포획한 에피소드만으로 낸 포획까지 평균 시간이다 | 소요 시간 | 지표 |
| 평균 시간 | 포획하지 못한 에피소드를 10초로 쳐서 전체 에피소드로 낸 평균이다 | | 지표 |
| 포획률 | 전체 에피소드 가운데 포획한 비율이다 | 성공률 | 지표 |
| 에피소드 seed | 초파리의 시작 위치와 비행의 난수를 정하는 seed다 | 평가 시드 | 지표 |
| 학습 seed | 학습 한 번의 난수를 정하는 seed다 | 시드 | 학습과 판정 |
| 후보 | 판정을 받는 학습 조건이다 | | 학습과 판정 |
| P | paired bootstrap 10,000회 가운데 후보의 평균 시간이 기준선보다 짧았던 비율이다 | P값 | 학습과 판정 |
| 뷰어 | 저장소에 올린 에피소드를 재생하는 웹 화면이다 | 뷰어 앱 | 녹화 에피소드 |
| 녹화 에피소드 | 학습 도중에 따로 돌려 저장한 에피소드다 | 평가 에피소드 | 녹화 에피소드 |
| checkpoint | 학습 도중 정해진 step에서 저장한 조준기 agent다 | 체크포인트 | 녹화 에피소드 |
| 발 | 0.15초 동안 이어지는 레이저 발사 한 번이다 | 샷, 사격 | 설정 |
| 보일 때 벌점 | 보상 항목 가운데 초파리가 보이는 step마다 받는 벌점이다 | | 설정 |
| 오발 | 0.15초 가운데 한 번이라도 빔이 초파리를 벗어난 발이다 | 미스, 빗나감 | 설정 |
| 고정 포대 | 방공포처럼 자리가 고정되어 조준 방향만 돌리는 조준기다 | | 고정 포대 전환 |
| frame stack | 최근 관측 여러 개를 이어 붙여 조준기 agent에게 주는 설정이다 | 프레임 스택 | 첫 SAC 학습 |
| 검출 모델 | 카메라 영상에서 초파리를 찾는 모델이다 | | 각속도 추적과 관측 확장 |
| 추적 보조 | 조준기 agent의 행동에 기준선의 추적 행동을 더하는 설정이다 | 어시스트, 보조 제어 | 레이저 조건의 SAC 재학습 |
| 신경 초파리 | 초파리 뇌의 신경 연결 일부를 계산해서 나는 초파리다 | 뉴럴 초파리 | 조준기 v0과 v1 |
| 자극 | 조준 방향이 신경 초파리 가까이에 오면 신경 초파리에게 보여 주는 가상의 시각 자극이다 | | 조준기 v0과 v1 |
| Stable-Baselines3 | SAC를 비롯한 강화학습 알고리즘을 구현해 둔 Python 라이브러리다 | SB3, 스테이블 베이스라인 | 학습과 판정 |
| Gymnasium | 환경이 갖출 함수 `reset`과 `step`의 모양을 정한 규격이다 | 짐, gym | 학습 코드의 흐름 |
| gain | 오차를 얼마나 세게 고칠지 정하는 곱셈 값이다 | 게인, 이득 | gain |
| residual RL | 기존 제어기가 낸 행동 위에 학습한 보정을 더하는 방식이다 | 잔차 학습 | 추적 보조의 계산 |
| 쏘는 기준 | 기준선이 쏠지 정할 때 어림한 빔까지 거리와 견주는 거리 값이다 | 발사 반경, 트리거 | 발사 행동과 오발 |
| SAC | Soft Actor-Critic. 연속 행동을 다루는 강화학습 알고리즘이다 | | - |
