# 보정 적용 후 비행 이론 점검

현재 모델은 실측 뇌 연결의 일부를 감각 입력 근사, 날개 운동 해독과 신체 물리에 결합한 혼합 모델이다. 회로 개입을 시험하는 연구 도구로는 사용할 수 있다. 그러나 **실제 초파리가 신경회로만으로 자연스럽게 비행하고 회피하는 것을 재현했다는 판정은 아직 부적합하다.** 보정 계수의 적용, 수치 안정성과 생물학적 타당성은 서로 다른 검사다.

이 문서는 2026-11-21 측정과 11-22의 원격 재확인 및 최종 회귀를 다룬다. [사전 계획](flight-theory-audit-plan.md), [용어](flight-theory-audit-terms.md), [사실 대장](flight-theory-audit-facts.md)을 함께 보존한다.

## 적용과 검증

원격 upstream/main을 두 날짜에 fetch했다. #59 작업 브랜치 HEAD와 같은 ee4c5a1이어서 새 병합은 필요하지 않았다. 실제 변경 폴더는 기존 FlyTracker-59 worktree다. 원래 FlyTracker checkout과 원본 프로젝트, 기존 결과 및 published는 수정하지 않았다.

기존에는 별도 calibrated_config()만 후보를 적용하고 일반 API 및 CLI는 원래 계수를 사용했다. 이제 새 NeuralConfig와 --fly-model neural 실행은 아래 실험용 후보를 사용한다. 프로필 ID는 zenodo29193-candidate13-experimental이다. 네 값은 이전 calibration-profile.json과 정확히 일치한다.

| 계수 | 원래 값 | 적용 값 | 역할 |
|---|---:|---:|---|
| drag_coefficient | 0.7 | 0.6965822171 | 날개 운동에서 유도한 선형 항력 |
| stroke_plane_forward_rad | 0.1745329252rad | 0.1652462364rad | 초기 날개 힘 기준의 전방 기울기 |
| saccade_rotation_gain_rad | 0.06rad | 0.0840676455rad | 선회 발화를 날개 회전 차이로 해독 |
| background_drive_hz | 1Hz | 1.0077175329Hz | 선택한 입력 뉴런의 외부 Poisson 구동 |

original을 명시하면 원래 계수를 사용한다. 보정 필드가 없는 과거 JSON도 원래 계수로 읽는다. 새 JSON은 프로필과 계수 수치를 저장하므로 새 기본값으로 과거 기록을 조용히 바꾸지 않는다. 기본 rule 모델의 관측, 행동, 보상과 난수 소비 순서는 유지했다. 환경 v6에서 설정된 신경 프로필이 바뀐 것이며 관측과 행동 규약의 새 버전을 만들지는 않았다.

```powershell
uv run python scripts/record_baseline.py --fly-model neural --episodes 1 --seed 10000 --no-save
uv run python scripts/record_baseline.py --fly-model neural --neural-profile original --episodes 1 --seed 10000 --no-save
uv run python scripts/record_free_flight.py --fly-model neural --no-aim --seconds 30 --no-save
```

첫 명령은 실제로 실행해 포획 1/1, 포획까지 5.39초로 종료했다. 단일 실행이므로 학습 성능이나 평균 포획률의 증거로 사용하지 않는다.

보정의 근거는 Hellekes 등의 Zenodo 29193이다. 제공 README의 조건은 4일령 암컷, 유전자 GFP 대조군, 단색 회색(gray) 시각 조건이며 실험마다 초파리 7마리가 있었다. 위치는 이미 Kalman 평활과 자료 선별을 거쳤다. 같은 종이라는 점은 장점이지만, 일반 야생형의 모든 평시 비행이나 현재 방의 벽과 텍스처 조건까지 대표하지 않는다. 개별 구간을 독립된 초파리 수로 세지 않는다. [자료와 CC BY 4.0 고지](https://zenodo.org/records/29193), [원문 README](https://zenodo.org/records/29193/files/README.txt?download=1)

기존 독립 평가의 6개 실험, 24구간에서 속력, 가속도 크기, 50ms 방향 변화각과 수직 속도의 분포를 비교했다. 실측과 모델 분포의 Wasserstein 거리를 학습 자료의 사분위 범위로 나눠 네 지표와 실험을 같은 비중으로 평균한 오차는 0.367910에서 0.352007로 감소했다. 같은 실험 쌍을 10,000번 재표집하고 동률을 절반으로 센 후보 우세 확률 P=0.879는 사전 문턱 0.90에 미달했다.

새 기본 선택은 사용자의 적용 요청에 따른 실험 설정이다. 이전 미채택 판정을 뒤집거나 신경-근육 변환까지 검증됐다고 해석하지 않는다. 기록에는 자료 SHA-256, 계수 해시와 preregistered_gate_passed=false를 남긴다.

포획을 끄고 seed 0,1,2에서 각 30초씩 다음 세 조건을 측정했다. 총 270초이며 신체 갱신 54,000회에서 신경 지연 큐와 운동 필터를 포함한 상태를 확인했다. 속력 분포는 20ms 기록 표본을 합친 값이다.

| 조건 | 속력 5/50/95 백분위 m/s | 날개 출력 포화/신체 갱신 | 가상 자극 |
|---|---|---:|---:|
| 원래 계수, 무자극 | 0.3400 / 0.3569 / 0.4403 | 2,096 / 18,000 | 0회 |
| 보정 후보, 무자극 | 0.3234 / 0.3433 / 0.4308 | 2,330 / 18,000 | 0회 |
| 보정 후보, 시선 연동 | 0.3196 / 0.3434 / 0.4311 | 2,213 / 18,000 | seed마다 3회 |

포화 횟수는 출력 제한이 하나라도 작용한 5ms 신체 갱신 구간을 1회로 센다. 같은 구간에서 여러 출력이 포화해도 중복 합산하지 않는다.

세 조건 모두 비유한 상태, 방 이탈, 접촉 보정, 1.5m/s 속도 경고와 300rad/s 각속도 경고는 0이었다. 자세를 표현하는 quaternion의 최대 정규화 오차는 2.22e-16이다. 보정 무자극의 수직 속도 5~95% 범위는 -0.2366~+0.1885m/s, 최대 bank(몸의 좌우 기울기)는 약 32.46°였다. 이 조건에서는 수평 움직임만 발생하지 않았다. 출력 포화는 실제로 있었으며 자연 비행 적합성의 통과 항목으로 처리하지 않는다.

3개 worker의 전체 경과시간은 191.25초다. 로컬의 다른 프로세스와 자원을 독점하지 않은 조건이므로 단일 환경 처리량이나 GPU 성능으로 환산하지 않는다. 각 실행은 30초이며 무제한 안정성의 증거가 아니다. [측정 코드](../../../../scripts/audit_neural_flight.py)의 원본 결과와 해시는 runs/issue59-flight-audit-20261121/measurement/에 있다.

시선 연동 조건은 4초 추적과 4초 이탈을 반복했다. 다만 기본 예산 3회가 첫 추적 구간에서 모두 소진돼 실제 자극은 120,1290,2460ms에만 제시됐다. 각 노출은 250ms였다. 이후 조준을 다시 해도 예산이 재충전되지는 않는다.

seed 0과 1에서는 첫 자극의 감각 입력이 관측됐고 자극 제시 시작으로부터 각각 105ms, 115ms 뒤에 escape로 전환했다. seed 2의 첫 두 자극은 20ms 표본에서 입력이 0Hz였고, 뒤에 나온 escape 전환 시각도 무자극 대조와 같았다. 이를 자극 도피 성공으로 세지 않는다. 첫 두 seed의 전환도 제시 시작 120ms를 더하면 초기 시선 정렬 이후 225/235ms다. 완전히 맞춘 한 발의 포획 유지시간 150ms보다 늦을 수 있으므로 충전 120ms만으로 포획 전 도피를 보장하지 않는다.

무자극 조건에도 escape/recovery가 나왔다. 여기서 phase는 발화율 문턱과 지속시간으로 붙인 표시다. 이 phase 문자열 자체가 신체를 임의로 회전시키는 스위치는 아니며 벽 감각이나 다른 회로 활동도 표시를 바꿀 수 있다. 외부 자극 발생, 감각 입력, 발화 변화, 무자극 대조 대비 운동 변화와 실제 회피 방향을 따로 판단해야 한다.

최종 전체 회귀는 250개 통과, 실패와 건너뜀 0개다. 실행 환경이 중간에 멈춰 표시된 경과시간은 6,292.11초였으며 계산 성능 비교에서 제외한다. 1차 전체 회귀의 검사 1건은 새 검증 상태를 이전 문자열로 검사해 실패했다. 검증 상태와 미채택 플래그를 함께 확인하도록 수정했다. 관련 XML은 같은 검증 폴더의 pytest-final.xml이다.

## 비행 과정의 분류

LIF는 입력을 막전위에 누적하고 문턱에서 발화하는 단순 뉴런 모형이다. 실제 연결 수를 사용한다고 개별 뉴런의 막 특성이나 감각-근육 변환까지 측정한 것은 아니다. 아래의 공학적 가정은 코드 오류와 구분한다.

| 단계 | 분류 | 확인한 내용과 한계 |
|---|---|---|
| 기본 실행의 보정 선택 | 수정한 연결 오류 | 후보가 학습 함수에만 연결돼 있었다. 새 API와 일반 CLI, 자유비행 CLI를 같은 프로필로 연결하고 과거 JSON은 원래 계수로 보존했다. |
| 각속도 진단 | 수정한 기록 누락 | 경고 기준은 있었으나 일반 신경 기록에 누적 횟수가 없었다. 5ms마다 집계하고 reset에서 초기화하도록 보완했다. |
| 연결과 LIF | 실측 구조 + 동역학 가정 | 뉴런 ID와 연결 수는 자료에서 오며 흥분/억제 부호는 원 모델의 분류를 사용한다. 공통 막 시정수, 시냅스 크기와 지연, 부분 회로 경계 입력은 가정이다. 뇌 전체나 날개 운동 회로를 포함하는 배쪽신경삭(VNC)을 재구성하지 않았다. |
| 감각 입력 | 강한 공학적 근사 | RGB 망막 대신 정답 위치, 속도, 높이와 벽 거리와 확대 원반 기하를 발화율로 바꾼다. 좌우 가중치와 포화는 설계값이다. 조준 방향 자체는 초파리에게 전달하지 않는다. |
| 평시 발화 | 부분 회로 경계 가정 | 선택한 상위 입력에 외부 구동을 주고, DNg02 발화율을 평균해 사용한다. 좌우 DNg02의 독립적 제어를 이 평균만으로 재현하지 못한다. |
| 기준 양력 trim | 공학적 평형 보정 | 질량과 중력으로 날개 기준 진폭을 역산하고 고정 seed 회로의 기준 발화로 정규화한다. 매 구간 속도나 중력을 직접 덮어쓰지는 않지만, 공중 비행의 시작 평형을 설계자가 공급한다. |
| 자세 안정화 | 회로 밖의 제어 보조 | 이상적인 신체 각속도를 적분해 자세 변화를 추정하고 비례 및 미분(PD) 안정화 토크를 계산한다. 초기 위쪽 기준을 제공하며 실제 VNC와 평형곤 신경회로를 계산하지 않는다. 자세를 직접 덮어쓰지 않는다는 사실이 이 제어기의 부재를 뜻하지 않는다. |
| 날개 운동 해독 | 미검증 공학적 변환 | 발화율의 제곱근, 문턱, 좌우 차이와 gain을 양력, 날개 회전과 힘 작용점으로 바꾼다. 알려진 신경 기능의 방향성에 근거하지만 수치 함수는 실측된 신경-근육 전달함수가 아니다. |
| 날개 힘과 항력 | 축약 물리 + 행동 제약 | 주기 평균 양력, 선형 항력과 고정된 초기 힘 기울기를 쓴다. 정속 명령은 없지만 힘-항력 평형이 좁은 속력 분포를 만든다. |
| 회전 감쇠와 적분 | 근거 있는 근사 + 수치 처리 | 문헌의 회전 감쇠 계수를 쓰고 신체와 quaternion을 적분한다. quaternion 정규화는 표현 오차를 줄이는 수치 처리이며 수평 복원 명령이 아니다. 날갯짓 주기 내 와류와 상세 공력은 생략했다. |
| 벽 회피와 접촉 | 감각 근사 + 강제 경계 보정 | 벽 접근을 감각 발화에 반영하고, 끝내 벽을 넘으면 위치와 법선 속도를 비탄성 접촉으로 보정한다. 후자는 강제 보정이다. 이번 270초에는 한 번도 실행되지 않았지만 기능은 남아 있다. |
| normal/escape/recovery | 상태 표시 가정 | 문턱과 지속시간은 설계값이다. escape 표시나 alarmed만으로 실제 위협 감지 또는 방향성 있는 회피를 입증하지 못한다. |
| 이전 Vast 전송 묶음 | 수정한 실행 위험 | 과거 압축본에는 새 프로필 파일이 없다. 재포장과 현재 파일 해시 검증 없이 대여하지 못하도록 사전 검사를 추가했다. 이번에 전송하거나 대여하지 않았다. |

구현 근거는 [신경 어댑터](../../../../flytracker/neural_fly.py), [날개와 신체 계산](../../../../flytracker/neuromechanics.py), [부분 회로 선택](../../../../flytracker/flight_network.py), [가상 자극 일정](../../../../flytracker/stimulus.py)이다.

DNg02가 날갯짓 진폭을 조절하고 좌우가 독립적으로 작용할 수 있다는 점은 기능 실험으로 지지된다. 그러나 현재의 양측 평균과 제곱근 해독식을 그 논문이 검증한 것은 아니다. [DNg02 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC9206711/)

DNp03, DNa15와 DNb01이 선회 네트워크를 이루고 날개 운동에 영향을 준다는 근거도 있다. 흥분성과 억제성 경로와 실제 운동 뉴런 연결을 생략한 단순 차이 계산이 같은 전달함수라고 볼 수는 없다. [DNp03 선회 네트워크 원문](https://pmc.ncbi.nlm.nih.gov/articles/PMC12977095/)

Cheng 등의 회전 감쇠 연구 표 2의 A 조건 계수는 구현 값과 맞고, 원문은 날개 운동과 회전 감쇠의 관계를 다룬다. 코드의 전체 평균 공력이나 모든 질량, 기하와 진폭 스케일링이 같은 연구에서 검증된 것은 아니다. [Cheng 등 2010 원문](https://engineering.purdue.edu/~xdeng/JEB10.pdf)

Shiu 등의 뇌 LIF 연구는 연결 기반 계산의 가능성과 한계를 지지한다. 그 연구의 감각-운동 예측 결과가 현재 부분 회로의 자유비행 정확도를 보증하지는 않는다. [Shiu 등 2024 원문](https://www.nature.com/articles/s41586-024-07763-9)

## 판정과 다음 검증

이론의 큰 연결 순서인 감각→신경 발화→날개 힘→신체 운동은 타당한 연구 방향이다. 신경 상태와 지연 큐는 계속 유지되고, 실제 LIF 출력을 바꾸면 비행도 달라지는 검사가 있다. 연결을 사용하지 않는 단순 애니메이션은 아니다.

그러나 실제 비행의 자연스러움을 입증하기에는 두 가지 장벽이 남는다. 첫째, 보정 후에도 기존 동일 자료의 독립 구간 속력 5~95% 범위는 0.3244~0.3832m/s로 실측 0.1183~0.5674m/s보다 좁았다. 이 수치는 이번 방 비행 표와 조건이 다른 기존 비교다. 둘째, 회로 밖 안정화와 미검증 운동 해독이 궤적을 구성하므로 좋은 궤적이 실제 신경 기제를 재현했는지 분리할 수 없다.

특히 정상 수평 평형을 가정한 식은 후보에서 약 0.3236m/s의 속력과 약 0.198초의 수렴 시정수를 준다. 이 값은 속도를 덮어쓰는 명령이 아니라 고정 힘 기울기와 항력에서 나오는 모델 성질이다. 계수 보정만으로 속력의 폭, 단속 선회, 수직 탐색과 도피 지연을 모두 해결할 수는 없다.

자세 감각과 능동 안정화 자체는 생물학적으로 필요한 요소이며 근거 없이 전부 제거할 대상도 아니다. 다만 현재의 정확한 각속도 입력, 초기 기준과 제어 gain을 실제 감각 및 근육 회로와 구분하고 독립 검증해야 한다. [자유비행 제어 검토](https://pmc.ncbi.nlm.nih.gov/articles/PMC4992712/)

우선순위는 다음과 같다.

1. 속력, 가속도, 선회와 수직 운동과 도피 지연을 각각 독립 조건에서 검증한다. 시선 정렬, 감각 입력, 발화, phase와 무자극 대비 방향 변화를 분리한다.
2. DNg02 좌우 출력과 VNC와 근육 변환을 기능 자료에 맞춰 구성한다. 현재 gain을 단순히 키워 반응을 과장하지 않는다.
3. 자세 안정화의 센서, 지연과 출력 기여를 대조 실험으로 분리하고, 실제 조건에 맞는 측정 가능한 값으로 보정한다.
4. 전방 힘 방향을 고정한 구조와 전방 시각 속도 제어의 생략을 재검토한다. 원본 인코더가 계산한 전방 flow는 현재 단계에서 수직 flow 구동으로 덮어써지므로, 해당 진단값이 있다고 전방 시각 속도 조절을 수행한다고 해석하지 않는다.
5. 새 신경 가중치나 회피 정책을 채택하기 전에 무자극 비행의 분포와 안정성도 통과하게 한다. 생존 보상만 높아진 결과를 자연 비행으로 채택하지 않는다.

이번에는 새 계수 탐색, 장시간 학습이나 실제 동물 실험을 수행하지 않았다. 미확인 발화-근육 변환과 종, 유전자형과 장치 차이를 남은 위험으로 유지한다. 근거 없는 추가 속도 확대, 임의 회전이나 자세 덮어쓰기는 추가하지 않았다.
