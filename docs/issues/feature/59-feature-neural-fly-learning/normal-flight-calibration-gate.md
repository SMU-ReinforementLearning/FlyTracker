# 평시 비행 분포 보정 계획

## 질문

FlyTracker는 고정 위치의 조준기 방향을 제어해 초파리를 추적하고 포획하는 학습 환경이다. 이번 작업은 조준기 없이 신경 초파리의 평시 비행을 비교한다. Zenodo 29193의 대조군 gray 조건에서 기존 신경 생체역학의 평시 비행 분포 오차를 소수의 운동 및 배경 입력 계수 보정으로 줄일 수 있는지 평가한다. 실측 값이나 후보 결과를 보기 전에 이 계획을 고정한다.

## 자료와 조건

- 원문 https://zenodo.org/records/29193 및 README.txt.
- 대조군 impaired=False, condition=gray. 메타데이터에서 4,331개 궤적 구간과 27개 실험 uuid를 확인했다.
- 4일령 암컷 D. melanogaster, 샘플 간격 0.01초. 추적 좌표는 m 단위다.
- 같은 개체를 실험 내에서 확실히 구분할 수 없다는 자료의 한계를 따라 uuid 단위로 분리한다.
- 파일의 공개 MD5를 검증하고 SHA-256을 별도 기록한다. CC BY 4.0 고지와 저작자를 보존한다.
- 3초 이상인 각 원래 궤적의 첫 301개 위치 표본만 검사하고, 위치가 유한하고 메타데이터의 dt가 0.01초이며 초기 속력이 0.05m/s 이상인 경우 선별 후보에 둔다. 시간 연속성은 자료 제공자의 dt 표기를 따르며 프레임 간격을 별도로 검사하지 않는다. uuid는 실험, oid는 추적 대상, startf는 구간의 시작 프레임을 식별한다. 각 실험에서 uuid, oid, startf 문자열 해시 순으로 최대 4개를 선택한다. 선택 목록과 자료 해시는 최적화 전에 고정한다. 유효 구간이 없는 실험은 사유를 남기고 표본 명단 고정 전에 처리한다.
- uuid를 SHA-256("flytracker59-normal-v1|" + uuid) 순으로 정렬해 앞 60%를 보정, 다음 20%를 개발, 나머지를 독립 평가에 둔다. 정수 개수는 내림하며 남은 것은 독립 평가로 간다.
- 실제 장치의 벽 형상과 몸 자세가 충분히 기록되지 않은 범위를 명시한다. 비교는 3초의 무조준, 가상 위협 원반 제시 없음, 방 접촉 보정 없는 조건부 자유비행이다. 시뮬레이터의 초기 위치와 속도는 해당 실측 구간에서 취하고 초기 몸 방향은 속도 방향과 평행한 roll 0으로 가정한다. 초기화 가정은 별도로 기록한다.

실측 좌표는 X/Y가 수평이고 Z가 위쪽인 좌표로 해석한다. 내부 신체 계산과 비교용 저장 위치는 이 좌표를 사용하며 FlyTracker 어댑터에서는 (X,Y,Z)를 (-Y,Z,-X)로 회전시킨다. 속도와 방향에도 같은 회전을 적용한다. 따라서 모델의 내부 Z 속도가 실측 Z 수직 속도에 대응하고 FlyTracker에서는 Y가 높이다. 초기 위치에는 이 회전 외의 이동을 더하지 않는다.

## 지표

제공된 실측 위치에는 이미 forward-backward Kalman 평활과 초기 구간 제거가 적용됐다. 이 분석에서 실측과 시뮬레이션 모두 100Hz 위치 표본에 [1,4,6,4,1]/16의 5점 평활을 적용한 뒤 같은 유한차분으로 속도와 가속도를 계산한다. 자료 제공자가 적용한 초기 제거와 별도로 실측과 모델 모두 처음 0.5초를 추가 제외한다. 끝의 평활 및 2차 미분 경계 4개 표본도 제외한다.

네 지표는 속력(m/s), 가속도 크기(m/s²), 50ms 간격의 3차원 진행 방향 변화각(deg), 수직 속도(m/s)다. 진행 방향 변화는 두 속력 모두 0.05m/s 이상인 표본에서만 계산하고 제외 수를 기록한다. 몸의 roll이나 yaw를 위치 궤적으로 측정했다고 표시하지 않는다.

각 실험의 실측 및 모델 표본 분포 사이 1차 Wasserstein 거리를 계산하고 보정 16개 실험의 선별 구간을 모두 합친 실측 분포의 IQR로 나눈다. 지표마다 하나의 고정 IQR을 사용한다. 어느 지표라도 IQR이 0이면 지표를 제외하지 않고 전체 보정 실행을 중단해 비식별 사유를 보고한다. 지표별 오차와 네 오차의 단순평균을 보고하며 실험별 동일 가중치를 사용한다. CSV는 실험 uuid를 id로, 네 정규화 오차를 열로 저장한다.

experiment-gate는 저장소의 후보 선택과 bootstrap 평가 스크립트 묶음이다. 모델과 실측의 분포 차이를 오차 CSV로 저장하고 정답 CSV에는 목표 오차 0을 넣는다. 이 두 CSV에 적용하는 점수 1-mae는 1에서 평균 정규화 분포 오차를 뺀 값이다. 반올림과 clipping을 하지 않는다.

## 기준선과 후보

비교 대상은 FlyTracker의 신경 생체역학 모델이다. 연결 자료에서 선택한 LIF 부분회로의 발화를 근육과 축약 날개 힘 및 토크로 해독하고 신체 동역학을 적분한다. 감각 부호화와 운동 해독에는 공학적 가정을 사용한다. LIF는 막전위가 임계값에 도달하면 발화하는 뉴런 모델이다. 기준선과 모든 후보는 아래에 설명한 뉴런 547개, 연결 16,344개의 동일한 확장 회로와 5ms 신체 및 0.1ms 신경 갱신을 사용한다. 기준선에는 기본 MechanicsParameters를 적용한다.

기준선 결과 CSV 해시를 후보 측정 전에 기록한다. 각 3초 구간 안에서 신경 가중치와 지연, 발화 및 근육 상태의 시간 연속성을 유지하며 서로 다른 구간은 reset한다.

회로는 동봉된 philshiu/Drosophila_brain_model의 연결 parquet와 flywire_annotations의 뉴런 주석 TSV를 사용한다. 기존 가공 CSV는 LPLC2, DNp06, DNg02 하위 유형, HSN/HSE/HSS와 각 DNg02의 연결 수 5 이상인 주석 보유 입력 상위 3개를 선택하고 선택 뉴런 사이의 원자료 연결을 유지한 273개 뉴런, 9,495개 연결의 부분회로다.

확장 단계에서는 먼저 LC4, LPLC1, DNp03, DNa15, DNb01, VES041 유형의 뉴런을 추가한다. 다음으로 DNp03, DNa15, DNb01, VES041의 각 목적 뉴런마다 Excitatory 열이 0보다 큰 입력을 Connectivity 내림차순과 뉴런 ID 오름차순으로 정렬해 상위 3개를 추가한다. 선택 뉴런 사이의 연결로 뉴런 547개, 연결 16,344개의 유도 부분회로를 구성한다. 추가 입력 후보는 연결 수가 5 이상이며 위 6개 유형의 집합 밖에 있는 주석 보유 뉴런으로 제한하고 자기 연결을 제외한다. 이 선택과 배경 구동은 모델 설계다. 별도의 회전 감각 및 근육 지연 반사도 사용하며 이 반사의 토크 계산은 공학적 보조 모델이다.

반사의 기준은 reset 시 초기 몸자세의 roll/pitch 방향이며 yaw에는 각속도 감쇠를 적용한다. 회전 오차는 각속도 적분으로 추정한 상대 위쪽 벡터와 초기 몸좌표에서 고정한 기준 위쪽 벡터의 외적으로 계산한다. 이 회전 오차와 각속도 감쇠로 요구 토크를 계산한다. 감각 지연 5ms와 근육 시정수 5ms를 적용하고, 신경 발화에서 계산한 날개 출력 수준으로 반사 출력을 제한한다. 이 출력을 좌우 날개 양력 차이, 회전 차이와 힘 작용점에 반영해 신체 토크를 만든다.

후보는 기존 값의 0.5~2배 범위에서 다음 네 계수만 변경한다. drag_coefficient, stroke_plane_forward_rad, saccade_rotation_gain_rad, background_drive_hz.

drag_coefficient는 날개 이동에 비례한 항력에, stroke_plane_forward_rad는 기준 날개 힘의 전방 기울기에 적용한다. saccade_rotation_gain_rad는 DNa15/DNb01 좌우 발화율 차이로 계산한 단속 선회 명령을 좌우 날개 회전 차이로 바꾸는 이득이다. background_drive_hz는 확장 단계에서 DNa15 또는 DNb01의 입력으로 선택된 상위 3개 뉴런 ID의 합집합에 주는 외부 발화율이다. 질량, 중력, 날개 기하와 나머지 설정은 고정한다. 목표 속도나 몸 자세를 반복해서 덮어쓰지 않는다.

numpy Generator seed 5901로 생성한 16개 Latin hypercube 후보를 로그 공간에서 미리 만들고 JSON과 해시를 고정한다. 후보 생성 seed 5901과 구간별 실행 seed는 별개다. 각 구간의 식별 문자열 해시로 실행 seed를 정하며 기준선과 모든 후보에 같은 구간 seed, 초기 위치, 속도 및 방향을 사용한다. 후보당 최대 30분, 전체 탐색 최대 90분의 로컬 상한을 두고 처리 비용을 먼저 측정한다. 상한으로 미완료인 후보는 누락 사유를 표시하며 후보 선택에 포함하지 않는다.

## 후보 선택

보정 16개와 개발 5개를 합친 21개 실험에서 각 후보의 오차를 모두 계산한다. experiment-gate holdout_select.py의 8개 seed와 2개 fold로 실험을 두 묶음에 나눈다. 한 묶음에서 네 지표를 동일 가중치로 평균한 점수 1-평균오차가 가장 높은 후보를 선택하고 반대 묶음의 성능을 계산한다. 이 선택 단계에는 네 지표 각각의 개선을 요구하지 않는다.

이 선택 결과를 집계해 가장 자주 선택된 후보 하나를 최종 후보로 고정한다. 동률은 후보 id의 사전순으로 정한다. 독립 실험은 최종 후보를 고정한 다음 평가한다.

## 문턱과 판정

독립 실험의 기준선 및 최종 후보 CSV에 paired_bootstrap.py --metric composite --composite "1-mae" --round none --resamples 10000 --seed 42 --threshold 0.90을 적용한다. P(후보 우세)는 동률 절반을 포함한다. 지표별 오차와 후보 점수에서 기본 점수를 뺀 차이의 95% 구간을 함께 보고한다.

수치 비정상, 샘플 누락, 코드나 신경 가중치 변경, 초기 상태 불일치는 비교 무효다. 전체 평균이 개선되어도 악화된 지표는 명시한다. 후보를 기본 모델의 계수로 채택하려면 각 지표를 독립 실험에서 평균한 오차가 네 지표 모두 줄어야 한다. macro P는 네 지표 평균 점수에서 후보가 우세한 bootstrap 비율에 동률 비율의 절반을 더한 값이며 이 값이 0.90 이상이어야 한다. 조건을 충족하지 못하면 후보 계수와 결과를 보존하고 원인을 기록한다.

## 실행 모델 검사

NeuralFly는 FlyTracker의 reset, step, pos 계약과 내부 신경 생체역학 계산을 잇는 어댑터다. 후보 계산은 이 어댑터가 사용하는 NeuromechanicalSimulation에서 수행한다. 최종 계수 JSON을 다시 읽어 같은 모델을 초기화하고 자료 선별에서 확정한 독립 실험 6개와 실험당 4구간, 총 24개 구간을 동일 플랫폼에서 재실행한다. 이 검사는 저장 계수의 적용과 실행 재현성을 대조한다. 학습 신경망이나 영상 추적기를 새로 학습하지 않는다. 별도의 방 비행 안정성 검사를 추가하고 비교 구간, 속도 및 자세 이상과 접촉 보정, 날개 출력 포화를 보고한다.

## 집계와 재현 세부 조건

gray는 자료 제공자가 지정한 회색 시각 배경의 대조 조건이다. 실험당 선택한 구간은 별개의 초파리 수를 뜻하지 않는다. 평시 보정의 적용 범위는 gray 대조 조건과 3초 구간이며 새 개체나 다른 장치로 일반화할 수 있는지는 후속 검증 대상이다.

선별 문자열은 uuid + "/" + oid + "_" + startf이며 UTF-8 SHA-256을 쓴다. 메타데이터에서 길이 3초 이상을 선별한 뒤 각 원래 궤적의 첫 301개 위치 표본만 읽는다. 이 첫 구간이 유한하지 않거나 초기 속력이 0.05m/s 미만이면 사유를 기록하고 같은 실험의 다음 해시 순 구간을 검사한다. 유효 구간이 없는 실험은 명단 고정 전에 제외한다.

평활은 위치 양끝을 끝값으로 2개씩 확장한 뒤 5점 합성곱으로 계산한다. 속도는 numpy.gradient의 중심 유한차분, 가속도는 그 속도의 같은 차분을 사용하며 edge_order=2다. 평활과 두 번의 미분이 영향을 주는 마지막 4개 표본을 제외한다. 남은 표본 i의 속력과 가속도를 계산한다.

변화각은 i와 i+5가 모두 남은 표본 범위 안에 있는 경우 두 속도 벡터의 50ms 각으로 계산한다. 변화각에서 두 시점 중 어느 하나라도 속력이 기준 미만이면 그 각 표본만 제외한다. 변화각 표본이 하나도 없으면 실측 구간은 선별에서 제외하고 모델 계산은 해당 후보의 오류로 처리한다.

IQR은 16개 보정 실험의 선택 구간 표본을 모두 합쳐 계산한 75%와 25% 분위수의 차이다. 5개 개발 실험은 IQR 계산에 사용하지 않는다. 후보 선택에는 보정 및 개발의 21개 실험을 합친 오차 행렬을 사용한다. 이 21개를 seed 42~49에서 각각 2개 fold로 나누고, 한 fold에서 후보를 고른 뒤 반대 fold의 성능을 계산하는 16개 선택 결과를 집계한다. 가장 많이 선택된 후보를 독립 실험 평가에 넘기며 횟수가 같으면 후보 id 사전순으로 정한다.

한 실험의 최대 4개 구간은 같은 지표의 모든 표본을 이어 붙여 하나의 분포로 계산한다. 변화각의 유효 표본 수는 속력 조건에 따라 구간마다 다를 수 있다. 각 실험의 네 정규화 오차를 동일 가중치로 평균하고 전체 실험도 동일 가중치로 평균한다.

독립 평가의 bootstrap 재표집 단위는 6개 실험 uuid이며 같은 uuid의 기준선과 후보를 함께 재표집한다. macro P는 네 지표의 평균 점수 1-평균오차에서 후보가 우세한 bootstrap 비율에 동률 비율의 절반을 더한 값이다. 네 지표 모두 개선 조건은 각 지표를 6개 실험에서 평균한 오차가 모두 감소해야 한다는 뜻이다.

95% 구간은 실험 uuid를 함께 재표집해 계산한 점수 차이 10,000개를 정렬하고 2.5 및 97.5백분위에서 선형 보간한 percentile bootstrap 구간이다.

기준값은 drag_coefficient=0.7(무차원), stroke_plane_forward_rad=0.1745329252rad, saccade_rotation_gain_rad=0.06rad, background_drive_hz=1Hz다. 각 기준값의 0.5~2배에서 로그 공간 Latin hypercube 후보 16개를 생성했고 prepared-final/profiles.json 해시를 기준선과 함께 고정했다. 후보 순서는 candidate-00부터 candidate-15다. 후보별 최대 30분을 적용하며 전체 90분 상한에는 기준선, 후보 선택 및 평가 계산을 포함한다. 완료 후보가 없으면 결과 오류로 종료한다.

각 구간의 seed는 선별 문자열 SHA-256의 첫 8개 16진수를 정수로 바꾼 뒤 2**31-1로 나눈 나머지다. 이 seed의 Generator로 NeuralFly를 reset하고 신경 전압, 시냅스, 지연 큐와 근육 및 발화 필터를 초기화한다. 초기 속도는 추가 평활 전 제공 좌표에서 (p[4]-p[0])/0.04초로 정하고, 속도 방향과 평행한 roll 0 자세를 초기 가정으로 사용한다. 각 구간 내부에서는 모든 신경 및 근육 상태를 연속 유지한다. 서로 다른 실측 구간은 별도로 reset한다.

phase는 normal, escape, recovery로 표시하는 모델의 행동 상태이며 phase 사건은 그 상태가 바뀐 시각의 기록이다. 저장 계수 재검사는 독립 평가의 같은 24개 구간을 계수 JSON 로딩 후 다시 실행한다. CPU 및 경과시간 필드를 제외한 simulate 반환 필드 전체가 정확히 같아야 한다. 이 필드에는 구간 ID, 실험과 seed, 표본 위치, 초기 속도, 궤적 특징, 유효 표본 수, phase 사건과 진단이 포함된다. 진단은 뉴런 및 연결 수, 가중치 해시, 신경 갱신 및 발화 횟수, 경계 보정과 날개 포화 및 속도 경고 횟수, 최소 높이, quaternion 정규화 최대 오차와 최종 상태 해시를 포함한다.

최종 상태 해시는 neural.voltage, synaptic, pending, next_active, motor.filtered, force_body, torque_body, reflex_activation, quaternion, 속도, 각속도 배열 및 신경 RNG 상태를 합쳐 계산한다. quaternion 오차는 매 신체 갱신에서 abs(norm(q)-1)을 계산한 최대값이다.

방은 FlyTracker 좌표에서 폭 4m, 높이 2.5m, 깊이 3m의 직육면체이며 바닥 중심이 원점이고 Y가 위쪽이다. seed별 Generator로 벽에서 0.4m 안쪽의 영역에 초기 위치를 균일 추출한다. 같은 Generator의 수평 성분 정규 난수 두 개와 크기 0.2배의 수직 정규 난수로 방향을 정규화한다. 실제 초기 위치와 속도는 room-baseline 및 room-candidate의 manifest.json에 저장한다.

방 검사는 seed 59001, 59002, 59003을 각각 30초씩 실행하며 기준선과 후보에 같은 초기 위치, 방향과 초기 속력 0.35m/s를 사용한다. 후보에서 유한하지 않은 상태, quaternion 오차 1e-8 이상 또는 기존 1.5m/s 속도 경고가 발생하면 채택하지 않는다. 접촉 보정과 날개 힘 포화는 수치와 함께 보고한다.

위 세부 조건은 기준선과 후보를 계산하는 코드에 구현된 절차를 풀어 쓴 것이다. 독립 결과를 확인하고 판정 문턱을 변경하지 않는다.

### 비행 분포의 차이

독립 평가 24개 구간을 합친 속력 중앙값은 실측 0.3206m/s, 보정 전 0.3497m/s, 후보 0.3349m/s다. 속력의 5~95% 범위는 실측 0.1183~0.5674m/s, 보정 전 0.3411~0.3868m/s, 후보 0.3244~0.3832m/s다. 후보의 중앙값이 실측에 가까워졌어도 모델의 속력 분포는 여전히 좁다.

실측과 보정 전의 95% 분위수는 가속도 크기에서 5.5635와 4.0564m/s², 진행 방향 변화각에서 52.5046°와 29.5203°다. 수직 속도의 5~95% 범위도 실측 -0.1907~+0.2273m/s, 보정 전 -0.1506~+0.1364m/s다. 그림 `experiment-final/heldout-distributions.png`의 실측, 보정 전, 후보 누적분포에서 이 차이를 볼 수 있다.

속력, 가속도와 수직 속도는 자료별 5,928개 위치 유래 표본이다. 변화각은 저속 조건 제외 후 실측 5,757개, 각 모델 5,808개다. 이 표본들은 같은 실험과 궤적 안에서 상관되므로 독립 표본 수로 세지 않는다. 통계 판정에는 위의 실험 6개를 사용했다.

### 신경 상태와 방 비행 검사

독립 평가 24개 구간의 계수 JSON 재로딩 실행은 CPU 및 경과시간을 제외한 위치, 궤적 특징, phase 사건을 포함한 진단과 검사 대상 신경 및 신체 배열의 최종 상태 해시가 24/24 일치했다. 모든 구간에서 뉴런 547개, 연결 16,344개와 같은 신경 가중치를 사용했다. 3초당 신경 갱신은 30,000회이며 독립 평가에서 phase 전환은 두 모델 모두 0회였다. 가상 위협과 조준기가 없는 조건이다.

방 검사는 seed 59001, 59002, 59003에서 기본 계수와 후보를 각각 30초씩 실행했다. 두 모델 모두 유한 상태이며 경계 접촉 보정 0회, 1.5m/s 초과 경고 0회, quaternion 정규화 최대 오차 2.22e-16이다. 날개 힘 포화는 18,000회 신체 갱신 중 보정 전 2,254회, 후보 2,396회였다. 각 seed의 보정 전 포화 횟수는 868, 702, 684회이며 후보는 902, 798, 696회다. 포화 증가도 후보의 한계로 남긴다. 30초와 3개 seed가 장시간 안정성 전반을 입증하지는 않는다.

### 자료 조건과 권리

원자료는 Hellekes, Villalba, Stowers, Graf, Panser, Campione, Straw가 2015-08-24 공개한 자료이며 DOI는 10.5281/zenodo.29193이다. 데이터에 적용된 CC BY 4.0에 따라 저자와 원문, 변경 내용을 기록한다. 여기서는 대조군 선별, 3초 절단, 추가 평활, 미분과 분포 집계를 수행했다. 원문 README에 따르면 제공 위치는 이미 forward-backward Kalman 평활을 거쳤고 초기 0.5초 제거 등 사전 필터링이 적용됐다. 이번 분석에서는 제공된 실측과 모델 위치에 같은 추가 처리를 하고, 두 자료 모두 첫 0.5초를 추가로 제외했다. 모델에서 이 시간은 초기 준비 구간에 해당한다. [공개 자료와 라이선스](https://zenodo.org/records/29193), [원문 README](https://zenodo.org/records/29193/files/README.txt?download=1)

각 실험에는 같은 유전자형의 초파리 7마리가 있었으나 구간별 개체를 구분할 수 없다. 공개 코드의 2015년 설정에서 gray 조건의 단색 gray.png와 메타데이터의 조건 문자열이 일치함을 확인했다. 단색 이미지의 이동은 텍스처 이동 단서가 되지 않는다는 해석이다. 자료의 rotation_rate는 가상 장면의 회전 속도 명령(rad/s), v_offset_rate는 수직 패턴 이동 속도 명령(m/s)이며 이 두 열에는 값이 남아 있다. 해당 자료가 사용한 정확한 코드 커밋은 확인되지 않았다. [2015년 공개 설정](https://github.com/strawlab/strawlab_freeflight_experiments/blob/1c956316cebd7a61dcde3ed90e512b1a2b75a1a0/data/conditions/combined_stimulus.yaml)

시뮬레이터는 높이와 수직 속도로 시각 흐름을 근사하며 실험 영상과 벽 형상을 재현하지 않는다. 초기 속도 방향에 몸 방향을 맞추고 roll=0으로 둔 것도 측정되지 않은 초기 자세의 가정이다. 이 결과의 적용 범위는 짧은 대조군 궤적의 운동 분포 비교다. 실제 신경 발화, 날개 운동, 몸 자세와 자극 반응 지연의 일치는 이번 자료로 확인할 수 없다.

### 계산 환경과 비용

Windows 11 10.0.26300, Intel Core Ultra 5 226V의 8코어, Python 3.12.16에서 worker 4개를 사용했다. 수치 라이브러리 스레드는 OMP, OpenBLAS, MKL 각각 1개다. numpy 2.5.4, h5py 3.16.0, matplotlib 3.11.2, Gymnasium 1.4.0, pyarrow 26.0.1을 사용했다. 수치 계산은 2,104.062초에 끝났다. 방 비행 30초당 경과시간은 보정 전 48.22~48.99초, 후보 48.80~49.47초였으며 같은 모델의 3개 seed를 병렬 실행한 조건이다. 호스트의 다른 프로세스를 독점하지 않았으므로 일반 처리량 수치로 확장하지 않는다.

실행 중 소스를 고정했고 `measurement-source`에 계산 소스 5개를 SHA-256과 일치하게 보존했다. 측정 당시 `scripts/calibrate_free_flight.py` 해시는 `0eacca2f13567735956edce5a85269e94dbdffed34b8bf1971b9908237827b7f`다. 최초 실행은 기준선 해시를 문서에 기록한 뒤 외부 감시 스크립트가 release 파일을 만들어 후보 계산을 시작하는 구조였다. 계산 후 재실행 편의를 위해 release 파일 대기를 제거했다. 기준선 CSV와 해시를 먼저 저장한 뒤 후보를 계산하는 순서는 같으며 측정 소스와 최종 소스에서 simulate 등 수치 계산 함수의 추상 구문 트리(AST), 즉 코드의 문법 구조가 동일함을 확인했다. runtime.json은 실제 측정 버전을 가리킨다.

다운로드 원본은 7개 파일의 공개 MD5와 SHA-256을 확인했다. 완성된 HDF5를 다시 검증한 뒤 이번 다운로드의 중복 임시 조각 약 1.7GB를 정리했다. 원자료 본파일과 이전 작업의 결과는 보존했다. 이번 보정에는 로컬 CPU를 사용했다.

## 재실행

저장소 루트에서 다음 명령을 실행한다. 기존 출력의 코드, 자료나 계수가 다르면 재사용을 거부한다. 새로운 비교에는 새 출력 폴더 이름과 결과를 보기 전에 고정한 평가 계획을 사용한다.

```powershell
uv sync --extra neural --extra dev --extra research
uv run python scripts/fetch_flight_dataset.py --directory runs/issue59-flight-calibration/raw
uv run python scripts/calibrate_free_flight.py prepare --data runs/issue59-flight-calibration/raw --output runs/normal-flight-reproduction/prepared
uv run python scripts/calibrate_free_flight.py benchmark --prepared runs/normal-flight-reproduction/prepared --output runs/normal-flight-reproduction/benchmark --workers 4
uv run python scripts/calibrate_free_flight.py run --prepared runs/normal-flight-reproduction/prepared --output runs/normal-flight-reproduction/experiment --workers 4
```

긴 run을 실행할 때는 같은 작업에서 progress.json과 표준 출력 로그의 갱신을 감시한다. 원래 실험에서는 watch-final.json과 experiment-final.log를 20초 간격으로 감시했다. 준비, 후보, 독립 평가, 재실행과 방 비행 단계의 진행 기록을 남긴다. 재현용 run에서 새로운 결과를 보더라도 이번 판정이나 후보를 다시 고르지 않는다.
