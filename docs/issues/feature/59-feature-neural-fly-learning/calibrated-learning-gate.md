# 보정 신경 초파리 순차 학습 계획

2026-11-20 사용자 요청에 따라 보정 프로필 적용, SAC 조준기 학습, 고정 조준기 상대 LIF 가중치 배율 학습을 순서대로 수행한다. 기존 기본 계수와 rule 기본값은 유지한다.

## 조건과 제한

- 기준 코드: upstream/main ee4c5a1. 환경 v6의 18차원 관측, yaw/pitch/fire 행동, 빔 반경 1.25mm와 한 발 0.15초 조건을 유지한다.
- 보정 프로필: Zenodo 29193 candidate-13. 이전 독립 평가 P=0.879는 채택 문턱 0.90 미달이었다. 이번 적용은 사용자 요청에 따른 실험 설정이며 자연 비행 검증을 통과했다는 뜻이 아니다.
- 조준기: SAC 200,000 step 요청, 4개 병렬 환경, seed 42, MLP 128×128, batch 256, replay 200,000, learning_starts 2,000, entropy coefficient 0.0001. 조준 추적 보조에 더하는 정책 행동 배율은 0.05다. yaw/pitch/fire 세 값 모두 정책이 출력한다. 초기 actor 평균은 yaw/pitch 0과 fire tanh(2), 초기 log 표준편차는 -4다.
- 학습 시간은 조준기 2,400초, 대여 전체 7,200초로 제한한다. 시간이나 사용량 제한으로 일찍 끝난 실행은 완료한 step 수를 따로 보고한다.
- 신경 학습: presynaptic cell type, side와 연결 부호가 같은 실제 LIF 연결끼리 양의 배율을 공유한다. 원자료의 연결과 부호를 보존하고 배율은 0.5~2다. 모든 연결을 독립 학습하는 방식은 아니다.
- ES는 잡음 sigma 0.12, 학습률 0.08, 4개 ± 후보 쌍, 세대당 공통 seed 2개, 8세대다. dev 20000~20003에서 생존 적합도가 가장 높은 체크포인트를 선택한다.
- 적합도는 생존시간/10초에서 신체 tick당 경계 보정 비율과 속도 경고 비율에 각각 0.05를 곱한 값을 뺀다. 생존시간 자체와 경계 보정도 별도로 보고한다. dev에서 고정 조준기의 포획이 0/4이면 유효한 회피 학습을 주장할 수 없어 신경 학습은 보류한다.
- 신경회로를 우회하는 직접 위치, 속도나 자세 명령은 추가하지 않는다.

- 조준기 초기화에는 학습용 seed 1000~1015의 기준선 궤적 16개를 쓰고, 정책 평균을 1,000 batch 지도 학습한다. 이는 모방 초기화 후 SAC 학습이며 처음부터 강화학습만 한 모델로 표시하지 않는다.

## 기준선과 독립 평가

조준기 비교는 기존 RuleAimer 대 학습 SAC다. 자극 없음과 시선 연동을 분리하고 각각 seed 30000~30011, 회당 최대 10초를 사용한다. 기준선 JSON과 SHA-256은 학습 전에 고정한다. 조준 점수는 포획 여부 + 0.1×(1-실행시간/10초)다.

신경 학습 비교는 동일한 학습 조준기와 원래 LIF 가중치 대 학습 가중치다. 상대 model.zip 해시를 고정하고 두 자극 조건 각각 seed 40000~40011을 사용한다. 평가 점수는 생존시간/10초다. 신경 학습 기준선 JSON 해시를 세대 학습 전에 고정한다.

최종 평가 seed는 학습과 선택에 쓰지 않는다. 짝지은 10,000회 bootstrap에서 후보 우세 확률이 0.90 이상이어야 개선을 채택한다. 자극 조건 중 하나가 퇴보하거나 비유한 상태가 있으면 채택하지 않는다. 포획, 생존시간, 자극 횟수, 도피 phase 전환, 경계 보정과 속도 경고를 함께 남긴다. 같은 seed도 정책이 다르면 시선 연동 자극과 궤적이 달라진다.

## 비용과 Codex 중단

Vast.ai 신규 두 학습의 총 예산은 $3다. 대여 전 크레딧을 기준으로 차이를 감시하며 $2.70에서 회수와 반납을 시작한다. 시간 요금과 전송 예약액을 먼저 확인한다. 기존 인스턴스에는 작업하지 않는다.

중단 기준은 GPU 사용률이 아니다. 로컬 Codex JSONL의 token_count.rate_limits에 기록된 5시간 및 주간 잔여 한도 중 더 작은 값이 5% 미만이면 중단한다. 정확히 5%는 중단하지 않는다. 기록이 없거나 30분 이상 오래됐거나 창이 만료되면 안전하게 중단한다. 대화와 인증 정보는 전송하지 않는다.

독립 로컬 controller가 설치 중에도 한도와 STOP을 확인한다. 학습 체크포인트를 주기적으로 회수하고 중단 시 가능한 결과를 내려받은 후 이번에 만든 인스턴스를 반납한다. 한도 때문에 대화가 끊겨도 controller가 감시를 계속한다. 계정 크레딧의 갱신 지연과 API 장애 때문에 $3를 수학적으로 보장할 수 없으므로 요금, 시간 상한과 비용 여유를 함께 둔다.

## 결과

아직 새 학습을 시작하지 않았다. 기존 Vast 결과는 이번 실행 성과로 사용하지 않는다.
