# 평시 비행 분포 원인 진단

## 계획과 조건

Issue #59의 기존 worktree에서 수행한다. 목적은 이미 관측한 좁은 속력 분포의 발생 경로를 식별하는 것이다. 이번 검사는 계수 채택이나 생물 행동 개선 판정에 사용하지 않는다. 기존 코드, 원본 자료, 기준선 및 이전 결과를 보존하며 진단 결과는 별도 runs/issue59-flight-diagnosis에 저장한다.

DNg02는 FlyTracker의 신경 생체역학 모델에서 평시 날개 진폭을 해독하는 뉴런 묶음이다. 실측은 Zenodo 29193의 4일령 암컷 D. melanogaster, 단색 회색 배경(gray) 대조 조건이다. 모델의 수직 시각 흐름은 높이와 수직 속도에서 근사하며, gain=0 대조는 이 근사의 영향을 분리하는 검사다. 실제 장치의 모든 시각 단서와 같다고 가정하지 않는다.

진단 가설은 고정된 날개 힘 방향과 빠른 병진 항력 수렴, DNg02 평균 발화와 50ms 필터, 수직 감각 피드백, 날개 출력 제한과 회전 반사다. 기본 식에서 수직 힘이 중량과 평형일 때 A=sqrt(mg/(K*cos(theta))), c=rho*S*Cd*4*f*A*r이며 수평 평형 속력은 mg*tan(theta)/c, 시간상수는 m/c다. A는 날개 반진폭(rad)이다. 식의 m은 질량, g는 중력가속도, K는 코드의 lift_scale, theta는 전방 힘각, c는 병진 항력계수다. rho는 공기밀도, S는 총 날개 면적, Cd는 항력계수, f는 날갯짓 빈도, r은 날개 유효 팔 길이다. 중량 평형 근사와 실제 신경 비행을 구분한다.

첫 검사는 기존 선별 중 train의 16개 실험 64구간만 사용한다. 기본 모델을 구간당 3초 실행하고 5ms마다 감각 입력, DNg02 세포별 및 평균 필터 발화, 날개 진폭, 다음 구간의 힘과 항력, 자세와 속도, 출력 제한 종류를 기록한다. 100Hz 위치와 기존 motion_features를 함께 계산하며 이전 기본 모델의 같은 구간 위치와 정확히 일치하는지 검사한다. 기존 독립 평가 6개 실험은 재선택에 사용하지 않는다.

원본 XYZ 좌표는 X/Y가 수평이고 Z가 위쪽이다. 두 번째 검사는 train 실험별 첫 해시 순 구간의 seed 16개로 동일한 합성 초기 조건을 반복한다. 원본 좌표 초기 위치 (0,0,0.5)m, 수평 +X 방향, 초기 속력 0.35m/s, roll/pitch/yaw 0을 기본으로 한다. 조준과 위협 원반 및 방 경계는 사용하지 않는다. 모든 조건은 3초이고 같은 seed를 짝짓는다.

| 조건 | 한 번에 바꾸는 요소 |
|---|---|
| base | 기본 모델 |
| initial-slow | 초기 속력 0.1m/s |
| initial-fast | 초기 속력 0.7m/s |
| tilt-half | 날개 힘 기준 전방 각도 5도 |
| tilt-double | 날개 힘 기준 전방 각도 20도 |
| no-vertical-flow | normal_flow_gain=0, 회색 배경 gray 조건과 수직 시각 흐름 근사의 차이를 보는 감도 검사 |
| weaker-reflex | 반사 고유주파수 절반, yaw 감쇠 시간 2배 |
| background-tenfold | 배경 입력 10Hz, 입력 민감도의 스트레스 검사 |

이 변경은 진단용 인스턴스에만 적용한다. 극단 조건의 비유한 상태나 적분 실패는 원래 오류와 발생 시각을 기록하며 부분 성공 표본으로 분포를 계산하지 않는다. background 10Hz는 실측으로 정한 값이 아니며 자연 비행 설정으로 채택하지 않는다.

세 번째 검사는 신경회로를 사용하지 않는 기계적 대조다. 일정한 중량 평형 날개 힘과 항력을 기존 integrate에 입력하고 힘각 5, 10, 20도와 초기 속력 0.1, 0.35, 0.7m/s의 3×3 조합에서 수렴을 해석해와 비교한다. 이 대조를 신경 비행으로 해석하지 않는다.

실측과 모델의 폭은 기존 100Hz 위치 처리의 5~95% 및 IQR(25~75% 폭)로 계산한다. 초기 차이는 0, 0.1, 0.5, 1, 3초의 수평 속력으로 보고한다. 신경, 힘 진단 집계는 초기 0.5초를 제외한 2.5초다. 감각은 해당 5ms 구간 시작에서 샘플한 입력이다. 운동 기록은 그 입력으로 구간 끝에 해독해 다음 5ms에 적용할 명령이며, 신체는 이전 명령으로 갱신된다. 합성 조건은 생물 개체 수가 아닌 시뮬레이션 seed 16개다.

원인 판정은 식으로 예측한 평형과 시간상수가 기계 대조 및 신경 실행의 수렴과 맞는지, 각 감도 조건에서 중심과 폭이 어떻게 달라지는지, 출력 제한이 실제로 활성화됐는지를 근거로 한다. 각 조건의 전 지표와 실패를 보고하며 결과를 보고 문턱이나 조건을 바꾸지 않는다. 기여가 작은 조건도 남긴다. 모델 코드, 자료 해시, 패키지와 호스트, 실행 시간 및 진행 기록을 저장한다. 로컬 CPU worker 4개, 전체 30분 상한과 20초 진행 감시를 사용한다.

## 실제 결과

2026-11-20 #59 작업트리에서 신경 비행 208회, 회당 3초를 완료했다. 첫 계획의 64개 실측 초기화 구간과 합성 조건 8개 × 16개 seed가 192회이고, 이후 진폭과 그에 따른 양력 상한을 완화한 대조 16회를 추가했다. 모든 실행에서 신경 가중치가 동일했고 수치 실패와 phase(정상, 도피, 회복의 진단 상태) 전환은 0회다. 이식 모델의 수치 경로 검사이며 생물 개체 수로 해석하지 않는다.

기존 64개 기본 모델의 위치 및 최종 상태 해시는 과거 보정 실행과 64/64 일치했다. 진단 도구의 기록 추가가 모델을 바꾸지 않았음을 확인했다. 데이터는 이전 train 16개 실험의 64구간이며 독립 평가 구간은 읽지 않았다. 같은 64구간의 속력 5~95% 범위는 실측 0.126892~0.592494m/s, 모델 0.341405~0.387371m/s로, 폭은 각각 0.465602와 0.045967m/s였다.

고정 전방 힘각 10도와 중량 평형의 근사식은 수평 평형 속력 0.340227m/s와 시간상수 0.196689초를 예측했다. 실제 64구간의 수평 속력 구간 평균의 중앙값은 0.344267m/s였고, 다음 날개 명령의 세계 힘 기울기 구간 평균은 5~95%에서 10.0002~10.1605도였다. 신경회로를 거치지 않는 기계적 대조 9개의 수평 속도는 지수 수렴 해석해와 최대 9.77e-7m/s 차이로 일치했다.

합성 조건의 초기 수평 속력만 바꾼 경우 아래 값으로 수렴했다. 값은 같은 16개 seed의 평균 수평 속력이다.

| 경과 시간 | 초기 0.1m/s | 초기 0.35m/s | 초기 0.7m/s |
|---|---:|---:|---:|
| 0.5초 | 0.325012 | 0.346451 | 0.376521 |
| 1초 | 0.342924 | 0.344606 | 0.346962 |
| 3초 | 0.345649 | 0.345649 | 0.345649 |

이 세 조건은 seed별로 기록한 수직 속도, 감각 및 운동 지표와 DNg02 세포별 필터 발화가 모두 동일했다. 첫 구간의 항력 0과 이후 이전 명령의 항력을 적용해 초기 속도 차이의 수축을 재구성했으며, 빠른 조건과 느린 조건의 기록된 X 위치 차이와 수축식으로 재구성한 X 위치 차이 사이의 최대 오차가 5.25e-15m였다. 이는 경계와 위협을 끈 이번 조건에서 초기 수평 속도 차이가 운동 명령을 바꾸지 않고 항력으로 소실되는 직접적인 검사다. 이 결과의 재현은 initial-speed-contraction.json에 남겼다.

신경 출력의 변동은 존재했다. 초기 0.5초 이후 64개 구간의 변동계수(std/평균)를 구간별 계산한 평균은 5ms DNg02 평균 발화율 1.445, 50ms 필터 후 0.346, 날개 진폭 0.153, 수평 속력 0.0249였다. 서로 다른 물리량의 변동계수이므로 각 단계의 인과 기여율로 해석하지 않는다. 평균화, 필터와 제곱근 운동 해독, 힘의 제한 및 물리 응답을 통과한 출력의 관측값이다.

다음 표는 합성 조건별로 모든 표본을 합친 5~95% 분포 폭이다. 속력과 수직 속도의 단위는 m/s, 가속도는 m/s², 방향 변화각은 deg다. 초기 위치는 모두 원본 좌표 (0,0,0.5)m이고 seed는 같은 16개다.

수직 감각을 끈 조건의 수직 속도 5~95% 범위는 -0.355~+0.411m/s였고 기본 조건은 -0.191~+0.168m/s였다. 합성 3초 뒤 높이 범위도 기본 0.422~0.564m에서 0.140~1.159m로 벌어졌다. 속력 폭 증가에는 큰 상하 운동 변화가 동반됐다. 이 조건을 자연 비행 개선으로 채택하지 않는다.

진폭 제한은 실측 초기화 64구간의 진단 표본 32,000개 중 4,792개(14.975%)에서 활성화됐고 날개 양력 제한은 4,255개였다. 전후 힘과 작용점 제한은 0개였다. 추가 대조는 max_stroke_amplitude_rad를 pi/2에서 2rad로 바꿨으며 이로부터 계산하는 날개 양력 상한도 함께 완화됐다. 합성 16개 seed의 진폭 제한은 8,000개 표본 중 1,031개에서 4개로 줄었다. 속력 폭 증가의 seed별 평균은 0.020800m/s였고 수평 평균 속력은 0.344186에서 0.346193m/s로 변했다. 전진폭 약 229도는 물리적 민감도 대조값이다.

추가로 기존 위치를 XY 수평면에 투영하고 같은 평활과 유한차분을 적용했다. 50ms 방향 변화는 두 시점의 수평 속력이 모두 0.05m/s 이상인 표본만 사용했다. 실측 64구간의 유효 각 표본은 15,119개, 같은 초기 조건 모델은 15,488개다. 3차원 방향 변화 지표에는 수직 운동도 섞이므로 수평 선회를 구분해 보고한다.

|---|---|---|---|
| 실측 | 64 | 6.448499 | 56.544309 |
| 실측 초기화 모델 | 64 | 0.335142 | 2.852959 |
| 합성 기본 | 16 | 0.232384 | 2.679334 |
| 합성 배경 10Hz | 16 | 4.416179 | 14.017447 |
| 합성 반사 약화 | 16 | 0.519406 | 3.318876 |
| 합성 진폭 상한 2rad | 16 | 0.239831 | 2.953959 |

배경 입력을 1Hz에서 10Hz로 높이면 합성 조건의 수평 선회가 증가했다. 이번 회로에서 입력과 운동 반응이 연결됨을 보여 주는 민감도 검사다. 실제 배경 발화율을 측정한 보정값으로 해석하지 않는다. 10Hz에서도 실측의 큰 선회 분포와 차이가 남았다.

첫 실행은 약 176초, 후속 상한 대조는 초기화 뒤 약 40초였다. 로컬 worker 4개를 사용했고 관련 회귀 검사와 일부 구간을 병행했다. 호스트를 독점한 처리량 측정값이 아니다. 패키지 버전은 environment.json, 코드, 자료 해시는 manifest.json에 기록했다. 핵심 검사 2개는 9.22초, 수평 투영 검사를 더한 최종 관련 회귀 33개는 29.23초에 통과했다. 실패와 건너뜀은 0개다.

수평 분해와 초기 속도 수축 분석을 실행 도구에 합쳤으며 신경 비행을 계산하는 run_case 함수의 구조는 측정 버전과 같다. 기존 비행 및 보정 소스 5개의 해시는 실행 전후 일치했다. 첫 측정 당시 진단 소스는 measured-diagnosis-v1.py로 보존했다. 첫 계획은 plan.md, 후속 계획과 실행 파일은 cap-control-plan.md 및 cap-control-runner.py에 따로 남겼다. 후속 상한 대조와 수평 분해는 첫 결과를 본 뒤 추가한 탐색적 진단이다.

새 출력 폴더에서 다음 명령으로 전체 진단을 재실행한다. 현재 도구는 처음의 8개 합성 조건과 후속 상한 대조를 한 번에 수행하고 --raw-series로 수평 분해를 추가한다.

```powershell
uv run python scripts/diagnose_free_flight.py --prepared runs/issue59-flight-calibration/prepared-final --previous runs/issue59-flight-calibration/experiment-final --output runs/new-flight-diagnosis --raw-series runs/issue59-flight-calibration/raw/series.h5 --workers 4
uv run python -m pytest tests/test_free_flight_diagnosis.py tests/test_flight_calibration.py tests/test_neuromechanics.py -q
```

그림은 diagnosis.png와 horizontal-diagnosis.png이며 모델 재생 시연과 구별되는 분석 그림이다. 원자료와 모든 상세 진단 결과는 Git에서 제외한 runs/issue59-flight-diagnosis에 있다. 자료의 출처와 CC BY 4.0 고지는 [기존 실측 보정 기록](normal-flight-calibration-gate.md)의 자료 조건 및 권리 절을 따른다.

## 해석과 한계

이번 조건의 직접적인 기전은 초기 기준으로 고정된 날개 힘의 전방 기울기와 항력이다. 기본 물리식이 약 0.34m/s의 수평 평형을 만들고 약 0.2초의 시간상수로 초기 속도 차이를 줄인다. 평시 신경 출력은 변동하지만 고정된 힘의 기울기, 필터와 진폭 및 양력 제한, 빠른 항력 응답을 거친 수평 속력은 좁게 모인다. 초기 속도 분포만 바꾸는 방법으로 지속적인 다양성을 만들기 어렵다는 근거를 확보했다.

이 운동 해독기에서 pitch 토크는 근육 반사의 요구 토크를 날개 힘 작용점의 이동으로 변환해 만든다. 반사는 각속도 적분으로 추정한 회전 오차와 각속도 감쇠를 사용한다. 초기 자세에서 날개 힘과 반사의 기준을 정한다. 평시 신경 출력에서 전후 힘과 pitch를 독립적으로 바꾸는 경로의 표현 능력이 후속 진단 및 설계 대상이다. 반사 주파수를 절반으로 낮춘 대조의 속력 폭 효과의 95% bootstrap 구간이 0을 포함했으므로 그 정도의 반사 약화를 주된 해결책으로 지지하지 않는다.

수직 감각 피드백은 상하 변동을 줄이는 역할을 했고 배경 구동은 수평 선회에 영향을 줬다. 같은 종과 시각 조건에 맞는 감각 입력, 배경 활동과 발화에서 날개, 근육으로의 해독 근거를 확보하고 이 경로를 보정하는 것이 다음 작업이다. 계수나 난수를 늘려 보이는 다양성을 맞추는 개선안을 이번 진단으로 승인하지 않는다.

모델의 감각, 근육 반사, 공력은 공학적 가정을 포함한다. 이 진단은 #59 작업트리의 고정된 비행 코드와 경계 및 가상 위협 없는 짧은 구간을 대상으로 한다. 실제 신경 발화나 날개 및 자세 자료로 원인을 검증한 결과와 구별한다. 모든 조건의 phase 전환은 0회였으며 정상 비행 진단의 범위를 유지했다. 학습 가중치나 기본 신경 비행 동작은 이번 작업에서 변경하지 않았다.
