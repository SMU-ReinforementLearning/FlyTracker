# 비행 보정 적용과 이론 점검 계획

2026-11-21 Issue #59의 보정 적용과 비행 이론을 확인한다. 이 검사는 새로운 계수 탐색이나 생물학적 성능 채택 시험이 아니다. 기존 candidate-13의 독립 평가 P=0.879와 미채택 판정은 변경하지 않는다. 사용자의 적용 요청에 따라 새 신경 실행은 이 실험 프로필을 선택하고 과거 설정은 원래 계수로 읽는다.

## 변경과 확인 범위

원격 main을 fetch한 결과 현재 HEAD와 같은 ee4c5a1이다. 새 커밋이 없어 병합이나 branch 전환은 필요하지 않다. 기존 미커밋 파일 24개와 patch는 runs/issue59-flight-audit-20261121/before/와 before.patch에 보존했다.

일반 API와 CLI의 새 신경 실행에 후보의 네 계수를 적용한다. original 프로필과 과거 기록 재생은 이전 계수를 사용한다. 기본 rule 모델, 관측, 행동, 보상과 포획 규칙은 유지한다. 신경 프로필의 ID, 수치, 자료 SHA-256과 통계적 미채택 상태를 기록한다. 후보를 실측 재현이 검증된 기본 이론이라고 표시하지 않는다.

## 점검 기준

- 코드 오류: 잘못된 설정 연결, 과거 설정 해석 변경, 시간 순서 또는 좌표 오류, 비유한 상태를 확인한다.
- 기계적 근사: 날개 주기 평균 힘, 선형 항력, 균일 타원체 관성과 quaternion 정규화를 분류한다.
- 공학적 보조: 초기 양력 trim, 이상적인 각속도 적분과 PD 안정화, 벽 감각 근사와 접촉 보정을 회로 자체와 구분한다.
- 생물학적 한계: 부분 뇌 회로와 실제 날개 근육 사이에 생략된 VNC 회로, 발화율-운동 변환, 날개/선회 분포와 자극 감각을 원문 및 제공 자료와 대조한다.

장기라고 부르는 이번 범위는 30초다. seed 0,1,2에서 원래 계수 무자극, 보정 계수 무자극, 보정 계수 시선 연동을 각각 실행해 총 270초의 모델 비행을 확인한다. 포획은 끄고 최대 시간에만 끝낸다. 시선 연동 조건은 4초 추적과 4초 이탈을 번갈아 제어하며 실제 자극 발생과 신경 phase를 따로 기록한다. 이 조준 일정은 진단 장치이며 정책 비교 점수가 아니다.

각 실행의 유한성, quaternion 오차, 속력과 수직 속력, 자세, 각속도, 경계 보정, 날개 출력 포화, 신경 및 운동 필터 상태를 확인한다. 속도 경고 기준 1.5m/s와 기존 적분 오류 조건은 유지하며 상태를 잘라 정상으로 표시하지 않는다. 실행 길이를 넘는 안정성을 주장하지 않는다.

평시 비행의 자연스러움은 속력 하나로 판정하지 않는다. 기존 독립 평가의 네 분포 오차, 경계 보정 의존도, 회로 밖 안정화와 생략한 감각/근육 기제를 함께 판단한다. 미측정 부분은 불확실로 남기며 논문과 다른 종·조건은 동일 조건 근거로 사용하지 않는다.
