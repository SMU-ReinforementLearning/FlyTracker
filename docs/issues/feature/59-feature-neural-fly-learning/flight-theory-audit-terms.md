# 비행 점검 용어

| 표기 | 뜻 | 쓰지 않을 말 | 정의 위치 |
|---|---|---|---|
| 보정 후보 | 공개 궤적으로 네 계수를 맞춘 candidate-13. 채택 문턱에 미달했다. | 검증된 실제 초파리 | 적용과 검증 |
| LIF | 입력을 막전위에 누적하고 문턱에서 발화하는 단순 뉴런 모형 | 실제 뉴런과 동일 | 비행 과정의 분류 |
| PD 안정화 | 자세 변화의 내부 추정치와 각속도로 복원 토크를 계산하는 비례·미분 제어 | 재구성된 VNC 회로 | 비행 과정의 분류 |
| trim | 기준 발화에서 중량을 지탱하도록 날개 진폭을 정하는 평형 가정 | 매 구간 속도 덮어쓰기 | 비행 과정의 분류 |
| phase | 발화율 문턱과 지속시간으로 붙인 normal/escape/recovery 표시 | 도피 성공 | 적용과 검증 |
| 출력 포화 | 날개 힘이나 작용점 요구가 설정한 출력 상한에 걸린 상태 | 수치 발산 | 적용과 검증 |
