# 보정 신경 초파리 순차 학습 재개

2026-11-23 사용자 요청으로 기존 Issue #59에서 두 학습을 순서대로 실행한다. 원격 main과 현재 HEAD는 ee4c5a1로 같다. 보정 프로필은 zenodo29193-candidate13-experimental이며 이전 실측 비행 분포 보정 비교의 후보 우세 확률은 P=0.879로 채택 문턱 0.90에 미달했다. 그 미채택 상태를 그대로 기록한다. 새 계수 보정이나 비행 물리 변경은 하지 않는다.

## 학습과 판정

목표는 초파리 신경회로 학습에 사용할 조준기를 준비한 뒤 그 조준기를 고정해 초파리를 학습하는 것이다. 규칙 조준기보다 뛰어난 조준기를 만드는 것은 필수 목표가 아니다. 결과 보고 후 사용자가 이 목적을 다시 명시해 해석을 바로잡았다. 사전에 정한 통계 비교와 실제 측정값은 그대로 보존한다.

조준기는 현재 환경 v6의 관측 18차원을 사용한다. SAC가 yaw/pitch를 학습하고 기존 RuleAimer 규칙으로 fire를 붙인다. 초파리가 보이면 규칙 추적 행동에 SAC 행동의 0.05배를 더하고 [-1,1]로 제한한다. 보이지 않으면 SAC 행동을 그대로 사용한다. 발사 자체를 학습한 모델이라고 표시하지 않는다.

모방 초기화는 학습용 seed 1000~1015의 기준선 궤적 16개와 batch 갱신 1,000회다. 이후 SAC seed 42, 300,000 환경 step, 병렬 환경 6개, MLP 128×128, batch 256, replay 200,000, learning_starts 2,000, entropy coefficient 0.0001로 학습한다. 조준 보조에 더하는 정책 행동 배율은 0.05다. 학습 시간 3,600초를 넘으면 실제 step 수를 기록하고 현재 모델을 저장한다.

학습된 조준기 가중치는 SHA-256으로 고정한다. 이 조준기를 상대하는 초파리의 LIF 연결 배율을 학습한다.

실제 LIF 연결 16,344개에 적용되는 81개 공유 배율을 최적화한다. 같은 presynaptic cell type, side와 부호의 연결이 배율을 공유하며 범위는 0.5~2다. 모든 연결을 독립 학습하거나 신경회로를 우회하는 직접 회전 명령을 학습하지 않는다. 보상 기반 ES는 16세대, 4개 ± 후보 쌍, 세대당 공통 seed 2개, sigma 0.12, 학습률 0.08이다. 개발 seed 20000~20003에서 최적 후보를 고른다.

적합도는 생존시간/10초에서 신체 tick당 경계 보정 비율과 속도 경고 비율의 0.05배를 각각 뺀다. 고정 조준기가 시선 연동 자극을 켠 개발 4회에서 한 번도 포획하지 못하면 유효한 회피 학습으로 볼 수 없어 신경 학습을 보류하고 보고한다. 성능이 오르거나 신경 학습이 반드시 완료된다고 가정하지 않는다.

시선 연동은 환경의 정답 기하에서 조준선 정렬이 2.5° 이내로 120ms 충전되면 별도의 가상 확대 원반을 250ms 제시하는 조건이다. 비정렬 충전 감쇠는 200ms, cooldown은 800ms, 예산은 최대 3회다. 초파리는 제시된 감각 자극만 읽는다. 실제 초파리가 시선을 감지한다는 주장이 아닌 공학적 실험 규칙이다. 이 문서의 무자극은 가상 시각 자극을 끈 조건이며 발사 유무는 별도로 구분한다.

조준기 기준선은 동일한 보정 초파리를 상대하는 RuleAimer다. 자극 없음과 시선 연동 각각 seed 30000~30011에서 최대 10초 실행하고 JSON 및 해시를 학습 전에 고정한다. 점수는 포획 여부 + 0.1×(1-실행시간/10초)다. 최종 모델은 같은 seed로 평가한다. 신경 학습은 고정 조준기와 원래 가중치의 seed 40000~40011 기준선을 별도로 고정한 뒤 후보의 생존시간/10초를 비교한다.

실행 전 계획에는 두 평가 모두 짝지은 10,000회 bootstrap에서 후보 우세 확률 0.90 이상을 개선 채택 조건으로 기록했다. 두 자극 조건 중 하나라도 퇴보하면 개선판으로 채택하지 않는다는 조건도 유지한다. 이 조준 우세 검사는 보조 비교이며, 초파리 학습용 상대 준비의 완료 조건과 구분한다. 모든 최종 평가는 CPU 추론으로 통일한다. 학습과 선택에 최종 평가 seed를 사용하지 않는다.

무자극 비행은 seed 60000~60005에서 원래 및 선택 가중치로 각 10초씩 검사한다. 이때 발사하지 않아 포획이 없고, 경계 보정이 대조보다 늘거나 속도 및 각속도 경고가 있으면 비행 건강 검사 실패로 남긴다. 이 검사를 통과해도 실제 초파리의 자연 비행이 검증됐다는 뜻은 아니다. phase는 신경 발화율 문턱과 지속시간으로 붙이는 escape 및 recovery 상태 표시다. 이 상태 전환 횟수는 자극 회피 성공과 구분한다.

## 비용과 감시

Vast.ai 두 학습 합계 예산은 $3다. 사전 조회 잔액은 $4.87868352637이고 인스턴스는 0개다. 시간당 $0.20 이하와 전송 예약액 $0.30 및 최대 2시간으로 여유를 둔다. 관측 크레딧 차이가 $2.70이면 회수와 반납을 시작한다.

로컬 독립 controller가 Codex 사용량 기록을 감시한다. 5시간 및 주간 잔여 한도 중 작은 값이 5% 미만이면 STOP을 제시하고 결과를 회수해 이번 인스턴스를 삭제한다. 정확히 5%는 유지한다. 기록이 없거나 30분 넘게 오래됐거나 한도 초기화 뒤 새 기록이 없을 때도 중단한다. GPU 사용률은 중단 조건이 아니다.

로컬 연결 중단의 보조책으로 Vast.ai가 컨테이너에 제공한 인스턴스 전용 키를 사용해 자기 ID만 2시간 뒤 stop하도록 예약한다. 개인 계정 API 키와 SSH 키는 전송하지 않는다. stop은 GPU 대여를 중단하지만 저장 공간은 남을 수 있으므로 최종 회수 뒤 destroy와 자원 부재를 확인한다. API 및 네트워크 장애에 따른 지연은 위험으로 남긴다.

진행 기록은 runs/issue59-vast-calibrated-20261123/controller-status.json이며 3분마다 및 단계 전환 때 체크포인트를 로컬에 회수한다. 비용, quota-watch.json과 lease.json도 같은 폴더에 둔다. 학습에 필요한 코드와 기존 동봉 신경 자료 및 고지만 전송 목록으로 선별한다. 실측 H5, 개인 키, .env, .git과 기존 runs는 제외한다.

인스턴스 중단 API 근거: [Vast.ai 공식 stop 명세](https://github.com/vast-ai/docs/blob/main/api-reference/openapi/yaml/stop_instance.yaml), [공식 컨테이너 환경 안내](https://github.com/vast-ai/docs/blob/main/guides/instances/docker-environment.mdx).

## 실행 결과

초파리 학습용 조준기를 준비해 고정한 뒤 신경 배율 16세대 학습에 실제 사용했다. 상대 준비는 완료했지만, 학습된 초파리는 생존시간이 늘었어도 비행 건강 조건에 실패해 기본값으로 채택하지 않는다. 조준 우세 확률 미달을 상대 준비 실패로 보고했던 이전 해석을 정정한다. 기존 기본값과 두 체크포인트를 보존한다.

원격 환경은 Ryzen 9 5900XT, 유효 CPU 16개, RTX 5060 Ti 8GB, driver 595.99.02, PyTorch 2.15.0+cu132와 NumPy 2.5.4다. 병렬 환경 6개로 SAC 300,000 step을 완료했고 actorChanged=true, stoppedEarly=false다. 학습 스크립트 시작부터 모델 저장까지 1,530.16초이며 기준선과 모방 초기화 시간이 포함된다. 신경 배율 16세대의 탐색과 개발 평가는 약 494초다. 최종 평가까지 전체 원격 스크립트는 2,507.23초였다.

조준기 평가는 seed 30000~30011, 신경 배율 평가는 seed 40000~40011이다. 각 조건 12회, 최대 10초, CPU 추론이다. 아래 평균 종료시간은 미포획의 10초도 포함한다. 조준기의 점수는 포획과 빠른 종료를, 초파리의 점수는 긴 생존을 선호한다.

| 평가 대상 | 자극 | 학습 전 포획 | 학습 후 포획 | 평균 종료시간 전 → 후 | 점수 우세 확률 |
|---|---|---:|---:|---:|---:|
| 조준기 | 없음 | 12/12 | 11/12 | 4.885 → 4.683초 | 0.2889 |
| 조준기 | 시선 연동 | 12/12 | 12/12 | 4.847 → 4.125초 | 0.8504 |
| 초파리 신경 배율 | 없음 | 8/12 | 7/12 | 6.775 → 7.873초 | 0.9898 |
| 초파리 신경 배율 | 시선 연동 | 8/12 | 5/12 | 6.588 → 8.186초 | 0.9692 |

조준기는 보조 비교의 두 조건 모두 우세 확률 0.90에 못 미친다. 이 사실은 그대로 기록하며 회피 학습용 상대 준비의 실패 판정으로 사용하지 않는다. 학습된 조준기는 시선 연동 자극을 켠 개발 seed 20000~20003의 4회에서 2회 포획해 신경 배율 학습의 선행 조건을 충족했다. 초파리는 같은 학습 조준기를 SHA-256으로 고정해 원래 배율과 선택 배율을 비교했다. 따라서 규칙 조준기보다 나은 조준기를 상대로 검증했다는 주장은 하지 않는다. 신경 배율 후보는 개발 평가만으로 선택했고 최종 평가 seed로 다시 선택하지 않았다.

초파리 생존시간 점수의 95% 차이 구간은 무자극 [0.0070, 0.2365], 시선 연동 [-0.00709, 0.33458]이다. 우세 확률이 문턱을 넘었어도 시선 연동 구간은 0을 포함한다. 작은 표본의 조건부 결과로 해석한다.

## 비행 품질과 산출물

무자극 6회, 각 10초 자유비행에서 속도 및 각속도 경고는 전후 모두 0이었다. 하지만 seed 60001에서 경계 보정이 0회에서 66회로 늘었고 최소 높이가 1.127m에서 경계값 0.02m로 낮아졌다. 무자극 평균 속도는 0.349m/s에서 0.387m/s로 바뀌었다. 대결 평가의 조건별 12회 합계에서도 경계 보정이 무자극 0 → 71회, 시선 연동 0 → 1회로 늘었다. 생존시간 증가를 자연스러운 회피로 해석하지 않는다.

학습 중 경계 보정의 tick 비율에 0.05를 곱해 빼는 벌점은, 자유비행 실패 사례에서 0.00165에 불과하다. 전체 신체 갱신 10초/0.005초=2,000회이므로 벌점은 0.05×66/2,000=0.00165다. 다음 실험에서는 경계 접촉을 후보 선택의 필수 조건으로 검사하고, 평시 비행 분포 유지도 별도 개발 조건으로 등록해야 한다. 이번 최종 평가를 새 후보 선택에 재사용하지 않는다. 더 긴 학습보다 경계 벌점 및 선택 조건 보완이 우선이다.

실제 연결 16,344개의 부호와 연결 구조는 유지하고 81개 그룹의 양의 배율이 모두 바뀌었다. 배율 범위는 0.5~2이며 양 끝에 도달한 값도 있다. 모든 연결을 독립적으로 학습한 결과나 생물학적 학습 법칙의 검증은 아니다.

결과 경로는 runs/issue59-vast-calibrated-20261124-public/artifacts/training-neural이다. 조준기 model.zip 파일 SHA-256은 0a3b7a30f6b2bbc851f8e9ef9f45fac7fdf4f615880c6dabfaf44ba792c65bc1이다. weights-selected.npz 파일 SHA-256은 54f75dd01b54d3e90bcbefc93d70014020ec96aa3c7b86c737976e372583412f이며, 파일의 압축 형식과 무관하게 배율 배열 및 호환성 정보를 계산한 논리 해시는 479f9f6737d3b9a2f866fce0c7a0dbe5610704c4e1668a4c8d7fc5dbf3bff6fd다. 호환성 정보에는 환경 설정, 소스 및 자료 해시와 신경 연결 순서가 들어 있다. 서로 다른 두 해시의 대상을 구분한다.

전송 경로 보완 후 로컬 전체 회귀는 255 passed, 실패와 건너뜀 0개, 116.77초다. 원격 사전 검사는 20 passed, 4.57초다. 회수한 조준기를 기존 load_opponent로 읽었으며 신경 배율 체크섬도 통과했다. 같은 무자극 조건의 seed 60001을 로컬에서 다시 실행해 경계 보정 66회, 최소 높이 0.02m와 속도 및 각속도 경고 0회를 재현했다. 결과는 audit 폴더의 analysis-results.json에 기록했다.

## 비용과 감시 한계

첫 인스턴스 62188296은 시작 제한 10분, 두 번째 62190154는 108MB SCP 전송 제한 300초로 종료하고 반납했다. 전송 대상은 코드, 자료와 출처 고지의 50개 파일이다. 세 번째 62191297에서는 그중 48개 파일을 약 324KB로 전송했다. 대용량 연결 parquet와 주석 TSV의 2개 파일은 공개 main의 고정 커밋 ee4c5a1에서 직접 받고 승인된 SHA-256을 검사했다. 계산 파일 50개의 내용은 그대로다.

최종 회수 압축본 SHA-256은 3ec09fb0de5adc2cb8d00ef67df2cb72b044638cfae021b293116adbab8dcafc다. 회수 확인 후 세 인스턴스 모두 반납했고 마지막 조회는 0개다. 최초 크레딧 $4.87868352637에서 $4.64494153487로 약 $0.23 감소해 합계 $3 이내다. 청구서 확정액이 아닌 관측 잔액 차이이며 후행 정산 가능성이 있다.

Codex 잔여 5% 미만은 발생하지 않았고 마지막 관측은 27%였다. 다만 로컬 감시 로그에 약 67분의 공백이 있다. 원격 스크립트는 2026-11-24 00:57:32 KST에 끝났지만 반납은 01:39:00 KST였다. 공백 원인은 확정하지 못했으며 이 구간의 연속 감시를 보장하지 못했다. 다음 대여 전에 서버가 로컬 heartbeat 만료와 작업 완료 후 유휴를 감지해 스스로 중단하도록 보강해야 한다. 현재 2시간 자체 중단만으로는 즉시 반납을 보장하지 못한다.
