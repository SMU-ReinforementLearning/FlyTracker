# 각가속도 조준기 실험 조건

2026-11-25에 학습을 시작해 2026-11-26에 결과를 쟀다. 결과는 맨 아래 "결과" 절에 있다. 판정 규칙의 원문은 같은 폴더의 `gate.md`(영어)이고, 이 문서는 발표와 보고에 쓸 수 있게 조건을 한국어로 정리한 것이다.

## 배경

issue #51에서 정책 혼자 조종하는 SAC 조준기는 레이저 명중 조건에서 600판 중 21판만 잡았다. #85에서 원인을 쟀다. 정책은 조준을 배웠지만 각속도 명령이 step마다 ±25°/s쯤 흩어져서, 빔이 초파리 둘레 3 mm 안팎에서 떨었다. 관측에는 가운데를 확대한 조준 오차가 있는데, 행동은 탐색할 때와 마지막 조준에 같은 눈금 하나(±180°/s)를 쓴다.

이 실험은 두 가지를 묻는다.

1. 행동을 각가속도로 바꾸면 정책 혼자서 한 발(0.15초) 내내 빔을 초파리 위에 둘 수 있는가.
2. 같은 정책이 언제 쏠지까지 배울 수 있는가.

## 조건

| 조건 | 돌리는 행동 | 쏘는 것 | 보상 변경 |
| --- | --- | --- | --- |
| `rate-rule` | 각속도 (지금 그대로) | 기준선 규칙 | 없음 |
| `accel-rule` | 각가속도 | 기준선 규칙 | 없음 |
| `accel-pen-rule` | 각가속도 | 기준선 규칙 | 행동 변화 벌점 100배 |
| `accel-fire-m03` | 각가속도 | 정책이 학습 | 오발 벌점 0.3 |
| `accel-fire-m10` | 각가속도 | 정책이 학습 | 오발 벌점 1.0 |

조건마다 학습 seed를 셋(0, 1, 2) 써서 모두 15개를 학습한다.

## 열의 뜻

### 돌리는 행동

정책이 내는 yaw, pitch 두 값이 무엇을 뜻하는지다. 값의 범위는 둘 다 −1~1이다.

| | 각속도 | 각가속도 |
| --- | --- | --- |
| 행동 1이 뜻하는 것 | 최대 각속도. yaw 180°/s, pitch 120°/s | 조준기의 각가속도 한계 720°/s². 한 step(0.02초)에 각속도를 14.4°/s 바꾼다 |
| 행동 0 | 멈춘다 | 지금 속도로 계속 돈다 |
| 조준에 필요한 0.3°/s가 행동 범위에서 차지하는 비율 | 0.17 % | 약 2 % |
| 조준기가 따라갈 수 없는 명령 | 낼 수 있다 (#51 모델은 88~95 %가 그랬다) | 낼 수 없다 |

각가속도 행동은 환경을 바꾸지 않고 학습할 때 씌우는 변환으로 넣었다. 목표 각속도는 `지금 각속도 + 행동 × 14.4°/s`이고, 환경은 전과 같이 각속도 명령을 받는다.

### 쏘는 것

- 기준선 규칙: 초파리가 보이고, 관측으로 어림한 빔까지 거리가 1.25 mm 안이면 쏜다. 조준기 v0과 v1이 쓰는 규칙이다. 이 조건의 정책은 돌리는 두 값만 내고, 발사 상태(`shot`)는 관측하지 않는다.
- 정책이 학습: 정책이 세 번째 값으로 쏠지를 정한다. 0보다 크면 쏜다.

### 보상 변경

기본 보상은 아래와 같고, 조건마다 한 항목만 바꿨다.

| 항목 | 기본값 | 바꾼 조건 |
| --- | --- | --- |
| 시간 벌점 (매 step) | 0.01 | |
| 빔까지 거리 벌점 (보일 때, log 눈금) | 최대 0.1 | |
| 놓쳤을 때 벌점 (안 보일 때) | 0.15 | |
| 행동 변화 벌점 (각속도 명령 변화의 제곱 평균에 곱함) | 0.01 | `accel-pen-rule`에서 1.0 |
| 포획 보상 | 10 | |
| 오발 벌점 (오발 한 번마다) | 0 | `accel-fire-m03`에서 0.3, `accel-fire-m10`에서 1.0 |

- 행동 변화 벌점 1.0: 최대 각가속도를 낼 때 step당 약 0.010이다. 빔을 3 mm에서 1.25 mm로 좁힐 때 줄어드는 거리 벌점이 step당 0.008이라 그와 견줄 만한 크기로 잡았다. 조정해서 고른 값이 아니다.
- 오발 벌점: 1초 늦게 잡는 손해가 0.5~1쯤이다. 값을 하나로 정하지 않고 가벼운 값과 무거운 값을 조건으로 나눴다.

## 조건끼리 견줘서 답하는 질문

| 견주는 조건 | 질문 |
| --- | --- |
| `accel-rule`과 `rate-rule` | 각가속도 행동만으로 조준이 되는가 |
| `accel-pen-rule`과 `accel-rule` | 행동 변화 벌점을 키우면 더 나아지는가 |
| `accel-fire-m03`, `accel-fire-m10`과 `accel-rule` | 발사를 정책에 맡겨도 되는가 |
| `accel-fire-m03`과 `accel-fire-m10` | 오발 벌점의 크기가 무엇을 바꾸는가 |
| 다섯 조건과 조준기 v1 | 추적 보조 없이 v1만큼 되는가 |

이 비교들은 결과를 설명하는 데만 쓰고, 채택 여부는 아래 판정 기준으로만 정한다.

## 판정 기준

학습을 시작하기 전에 적어 commit했다(7a8ec50).

- 평가: seed 20000~20199의 200판. 학습에 쓰지 않은 seed다.
- 지표: 포획까지 걸린 시간. 못 잡으면 10초로 친다. 조건의 값은 세 모델의 평균이다.
- 견주는 상대: 조준기 v0(규칙 조준기). 같은 200판에서 평균 4.894초, 198판 포획, 판마다 오발 0.50발이다.
- 채택: 같은 seed끼리 짝지은 bootstrap(10,000회)에서 v0보다 빠를 확률이 0.90 이상이다.
- 채택에서 빼는 경우
  - 포획률이 0.97 아래다.
  - 세 모델 중 하나라도 v0보다 빠를 확률이 0.50 아래다. 이때는 "미정"이다.
  - 판마다 오발이 v0의 두 배(1.00발)를 넘는다. 이때는 "미정"이고 사용자가 정한다.
- 다섯 조건을 같은 상대와 견주므로, 실력이 v0과 같아도 하나쯤 운으로 넘을 확률이 41 %쯤 된다. 문턱은 낮추지 않고, 다섯 중 몇 개가 넘었는지를 함께 적는다.

참고로 조준기 v1(추적 보조를 쓴 SAC에 규칙 발사)은 같은 200판에서 평균 3.026초, 600판 중 584판 포획, 판마다 오발 0.60발이다(#72).

## 결과

2026-11-26에 쟀다. 15개 모두 1,000,000 step까지 학습했다. 다섯 조건 중 `accel-pen-rule` 하나가 채택 기준을 넘었다.

### 판정

| 조건 | 평균 시간 (초) | 포획 (600판) | 판마다 오발 | v0보다 빠를 확률 | 판정 |
| --- | --- | --- | --- | --- | --- |
| `rate-rule` | 9.967 | 12 | 19.58 | 0.000 | 기각 |
| `accel-rule` | 3.021 | 579 | 0.69 | 1.000 | 기각 (포획률 0.965로 0.97 미달) |
| `accel-pen-rule` | 2.611 | 589 | 0.47 | 1.000 | 채택 |
| `accel-fire-m03` | 10.000 | 0 | 0.007 | 0.000 | 기각 |
| `accel-fire-m10` | 10.000 | 0 | 0.007 | 0.000 | 기각 |
| 조준기 v0 (견주는 상대) | 4.894 | 200판 중 198 | 0.50 | | |
| 조준기 v1 (참고) | 3.026 | 584 | 0.60 | | |

- `accel-rule`은 시간으로는 v0을 확실히 이겼지만 포획률이 미리 정한 0.97에 못 미쳐 기각이다. 규칙을 먼저 적었으므로 그대로 따른다.
- `accel-pen-rule`은 세 모델 모두 v0보다 빠를 확률이 1.000이고, 포획률은 0.982, 오발은 v0보다 적다.
- `accel-pen-rule`은 v1보다도 0.41초 빠르게 나왔다(빠를 확률 1.000). 다만 v1과의 비교는 판정 대상으로 미리 적지 않았고 행동 변화 벌점도 한 값만 써 봤다. v1을 바꾸려면 v1을 상대로 한 판정을 따로 해야 한다.

모델별 값은 `gate.md`의 Verdict에, bootstrap 출력 전체는 `gate/bootstrap-output.md`에 있다.

### 조준이 좋아진 이유

issue #85와 같은 방법으로 쟀다. 발사를 끈 채 200판을 10초씩 돌리고 빔과 초파리 사이 거리를 기록했다. 값의 범위는 조건의 세 모델이다.

| 조건 | 빔까지 거리 중앙값 (mm) | 오차 방향이 뒤집힌 step | yaw 명령이 step마다 바뀐 크기 (°/s) | 반경 1.25 mm에 0.15초 머문 판 (200판) |
| --- | --- | --- | --- | --- |
| 조준기 v0 | 0.05 | 5 % | 5.7 | 198 |
| `rate-rule` | 2.82~3.12 | 86~89 % | 46.6~52.4 | 5~7 |
| `accel-rule` | 0.40~0.50 | 14~22 % | 3.6~4.0 | 191~195 |
| `accel-pen-rule` | 0.48~0.56 | 11~24 % | 2.9~3.2 | 193~198 |
| `accel-fire-m03` | 0.63~0.79 | 10~27 % | 3.2~3.6 | 182~199 |
| `accel-fire-m10` | 0.83~1.05 | 15~29 % | 2.9~3.9 | 188~200 |

거리는 초파리가 보이고 빔에서 20 mm 안인 step에서 쟀다.

- `rate-rule`은 #85에서 본 #51 모델과 같다. 빔이 초파리 둘레 3 mm에서 떨고, 명령의 86~94 %는 조준기가 따라갈 수 없는 크기다.
- 각가속도 조건은 명령 변화가 규칙 추적기 수준(같은 관측에서 3.8~4.6°/s)으로 줄었고, 빔이 반경 안으로 들어왔다. 조준기가 따라갈 수 없는 명령은 하나도 없다.
- 학습 중에도 포획이 보였다. `accel-rule`과 `accel-pen-rule`은 에피소드 평균 길이가 500 step에서 129~182 step으로 줄었다. `rate-rule`은 끝까지 500 근처였다.

### 발사 학습이 실패한 모습

발사까지 학습한 여섯 모델은 조준은 잘 배웠다. 위 표의 마지막 열처럼, 누가 쏴 주기만 했으면 200판 중 182~200판을 잡았을 만큼 빔을 초파리 위에 둔다. 그런데 쏘지 않는다.

- 정책의 발사 값은 빔이 초파리 위에 있든 멀리 있든 −0.5 안팎으로 같다. 0을 넘어야 쏜다.
- 학습할 때처럼 행동을 분포에서 뽑아도 발사 값이 0을 넘는 step은 0.1 % 이하다. 50판에서 판마다 0.02~0.22발을 쐈고 모두 오발이었다.

조준을 못 하던 학습 초반에는 쏘는 발마다 오발 벌점만 받았을 것이고, 그래서 조준을 배우기 전에 쏘지 않는 쪽으로 굳었다고 본다. 굳은 이유는 추정이다. 학습 초반의 발사 기록은 남기지 않았다.

### 한계

- 규칙 초파리, 평가 seed 200개에서 잰 값이다. 신경망 초파리와 관측 잡음은 다루지 않았다.
- 행동 변화 벌점 1.0은 한 값만 써 봤다. 더 좋은 값이 있는지는 모른다.
- "반경에 0.15초 머문 판"은 발사를 끄고 잰 값이라, 실제로 규칙이 쏘았을 때의 포획 수(판정 표)와 조금 다르다.
