## Current State

Issue #31의 신경 비행은 **신경 날개 모델 하나만 실행한다.** 신경 날개 모델은 LIF 발화에서 날개 힘과 토크를 계산해 신체 운동을 적분하는 `neuromechanical` 모델이다. 환경 API와 기준선, 학습 CLI의 초파리 기본값은 기존 `rule`이며, `neural`을 선택하면 신경 날개 모델을 사용한다. 실제 초파리 행동과의 일치는 아직 검증하지 못했다.

기준선은 `published/2026-11-11_133858_baseline`의 기존 rule 실행을 뜻한다. 로컬 원본 프로젝트는 사용자가 지정한 flysim 코드와 신경 자료가 있는 외부 디렉터리다. 기준선과 로컬 원본 프로젝트를 보존하고, 현재 신경 모델의 run 3개만 `runs`에 남겼다. 폐기 모델의 구현, 전용 검사와 이전 결과물은 사용자 요청에 따라 삭제했다. 삭제 목록과 보존 검사는 [공개 검증 요약](31-feature-neural-flight/validation-summary.json)의 preservation에 기록한다.

## 구현 계약

모델의 인과 관계는 감각 입력, LIF 회로, 날개 운동 해독, 신체 동역학으로 이어진다. 구간 내 계산은 이전 운동 명령을 유지하는 지연 구조를 따르며 아래 시간 계약에서 설명한다. 초파리는 조준 방향을 읽지 않고 환경이 제시한 가상 자극만 감지한다. 시선 연동은 조준기의 방향에 따라 별도 자극을 제시하는 실험 규칙을 뜻한다. 원본의 Gym, PPO, RGB 검출, viewer, SpatialMotor와 원형 공간 유지 제어는 이식하지 않았다.

| 파일 | 현재 역할 |
|---|---|
| `flytracker/neural_fly.py` | 로컬 모듈 로더, 신경 비행 어댑터, 좌표 변환, 접촉 보정, 출처, 진단 |
| `flytracker/flight_network.py` | 원자료에서 필요한 연결을 메모리로 선별하고 가공 CSV와 대조 |
| `flytracker/neuromechanics.py` | 감각 결합값, LIF 초기화, 발화 필터, 날개 힘, 토크, 근육 피드백, 신체 적분 |
| `flytracker/stimulus.py` | 정렬에 따른 충전, 감쇠, 확대 원반 제시, cooldown, 예산 |
| `flytracker/env.py` | 모델 선택과 신경 모드의 5ms 하위 구간 |
| `flytracker/record.py` | 기존 프레임 구조에 선택적 신경, 자극 정보 추가 |
| `flytracker/free_flight.py` | 무조준 비행 및 포획 종료 없는 조준 관찰 |
| `scripts/record_neural_demo_suite.py` | 현재 모델의 시연과 회로 억제 대조 생성 |
| `scripts/validate_neuromechanics.py` | 현재 모델의 반응, 회로 대조, 긴 비행 검사 |
| `scripts/inspect_flight_reference.py` | 외부 행동 자료의 단위, 자세 검사와 집계 |

실제 연결 데이터에서 얻은 547개 뉴런과 16,344개 연결을 사용한다. LC4, LPLC1, LPLC2, DNp03, DNp06, DNg02, DNa15, DNb01, VES041과 일부 입력 세포를 포함한다. 부분 회로의 선택과 외부 입력 부여, 흥분, 억제 부호 해석, LIF 매개변수는 측정 연결 자체와 구분하는 모델 가정이다. 뇌 전체나 복측 신경삭(VNC)의 운동 회로를 재구성한 것은 아니다.

원본 좌표 (X,Y,Z)를 FlyTracker (-Y,Z,-X)로 회전 변환한다. 내부 quaternion과 물리는 원본 좌표를 유지하며 위치, 속도, 자세, 각속도와 자극 위치를 어댑터 경계에서 일관되게 변환한다. 원본 파일은 지정한 경로에서 읽고 메모리에서 실행하며, 원본 초기화 파일, 출력 스크립트, pyc 생성은 실행하지 않는다.

신체 5ms 구간의 시작에서 감각을 샘플링한다. 이전 구간에서 해독한 날개 명령으로 신체를 갱신하고, 고정 입력으로 0.1ms LIF 계산을 50회 수행한 뒤 다음 날개 명령을 해독한다. 신체 계산 내부의 적분 간격은 1ms다. 환경은 각 5ms 구간에서 정렬, 자극 판정, 신경 비행, 조준기 적분 순서로 갱신한다. 시야와 포획은 10ms, 행동과 기록은 20ms 주기를 유지한다.

rule의 기존 10ms 조준기 적분은 유지하므로 두 모드의 조준기 적분 간격은 다르다. 지원하지 않는 시간 간격은 반올림하지 않고 거부한다.

회로의 전압, 시냅스 상태, 지연 큐, 발화 필터, 운동 상태(phase: normal, escape, recovery), 날개 명령과 근육 지연 상태는 reset 때만 초기화한다. 환경 위치, 방향을 표본화한 뒤 신경 모드에서만 별도 seed를 뽑는다. LIF 입력 난수는 그 seed, 초기 속도는 seed+300000을 사용한다. 기준 발화 보정은 무손상 회로와 고정 seed 314159로 별도 계산한다. 이전 운동 해독기의 난수 스트림과 OU 방향 난수는 실행하지 않는다.

### 가상 자극과 포획

가상 looming은 공간의 확대 원반으로 제시하는 실험 자극이다. 조준기 위치에서 본 초파리 방향과 조준 방향의 각도로 정렬을 판단한다. 기본 설정은 시야 안에서 2.5° 이내 정렬, 120ms 충전, 비정렬 시 200ms에 완전 감쇠, 250ms 제시, 제시 종료 뒤 800ms cooldown, 최대 3회다. 원반 반지름은 0.01m에서 0.12m까지 증가하며 대비는 1이다. 30초 반복 관찰에서는 예산을 100회로 명시적으로 늘린다. 이 수치는 생물학적 위협 역치가 아닌 실험 규칙이다.

정렬 → 가상 원반 제시 → 감각 입력 → LIF → 날개 해독 → 운동 변화 순서로 연결한다. 벽의 시각 입력도 같은 회로에 들어가므로 가상 자극이 없어도 도피 phase가 발생할 수 있다. 기존 거리 기반 도피는 신경 모델에 중복 적용하지 않는다. 실제 빛이 항상 위협이거나 초파리가 시선을 읽는다는 주장을 하지 않는다.

120ms 충전이 200ms 포획 유지보다 짧아도 감각 감지나 포획 전 도피를 보장하지 않는다. 충전 완료 구간 끝에 자극 시작 시각을 예약하고, 그 시각의 신경 샘플 전에 포획되면 노출은 0이다. 자극 제시, 감각 입력, 발화와 phase, 실제 궤적 변화는 각각 기록하고 판정한다. `escape`와 `recovery`를 `alarmed=True`로 표시한다.

좌우 DNp06과 DNp03 필터 발화 중 최댓값이 40Hz 이상으로 15ms 지속되면 escape로 들어간다. 그 최댓값이 5Hz 이하로 100ms 지속되면 recovery로 옮기고, 회복 500ms 후 normal로 돌아간다. 문턱과 phase는 이 모델의 진단 규칙이며 행동 실측으로 보정한 판정이 아니다.

### 날개, 신체 가정

고정 속도 명령, 속도 추종 가속도, 관찰용 속도, 고도 증폭과 quaternion을 직접 덮어쓰는 수평 복원은 사용하지 않는다. 속도는 날개 힘, 중력, 병진 항력과 회전 감쇠를 적분한 결과다. 초기 속도는 normal(0.356,0.183)m/s를 [0.05,1]로 제한해 reset 때 한 번 표본화한다. 이 초기 분포를 비행 중 목표 속도로 사용하지 않는다. 평균 0.356은 [기존 비행 근거 문서](9-feature-fly-realism-search/fly-flight-and-search-model.md)의 긴 구간 값을 참고한다. 정규분포와 절단 범위는 공학적 가정이며, 표준편차 0.183은 참고 문서의 약 0.19와 차이가 있어 원문 조건의 재확인이 필요하다.

현재 DNg02 평균 필터 발화를 고정 seed의 무손상 기준 발화율로 나눈다. 그 비율의 제곱근에 중량 평형 진폭을 곱해 날개 진폭을 계산하고, 양쪽 날개 힘 차이와 전후 힘에서 토크를 계산한다. DNp03/DNp06과 DNa15/DNb01의 좌우 발화 차이가 선회 운동에 기여한다. 발화에서 근육, 날개로의 이득, 모집 문턱, 기하와 양력 계수는 실측 보정 전 공학적 가정이다.

각속도 감각을 내부 적분한 상태와 5ms 지연을 이용해 기능적 근육 피드백을 계산한다. 실제 quaternion이나 세계 수평을 매 구간 읽어 자세를 복원하지 않는다. 다만 reset 때 초기 자세로 날개 힘의 기준면과 감각 기준을 정한다. 이 초기 기준 설정도 모델 가정이다. 날개 출력이 없으면 이 피드백으로 부양하거나 자세를 복원할 수 없다.

회전 감쇠에는 Cheng 등(2010, DOI `10.1242/jeb.038778`) 표 2의 계수와 좌표 변환을 사용한다. 주파수 스케일링은 문헌 근거이며 진폭 스케일링은 축약 근사다. 다른 신경, 운동 참고 문헌의 DOI는 각 에피소드의 `meta.neural.neuromechanics.sources`에 기록한다. 날갯짓 주기 내부의 비정상 공력과 실제 VNC 시냅스는 구현하지 않았다.

벽 회피는 접근 확장을 감각 입력으로 바꿔 회로에 전달하는 공학적 근사다. 최종 접촉에서는 0.02m 여유 안으로 위치를 제한하고 법선 속도를 안쪽으로 반사한 뒤 0.2배로 줄인다. quaternion, 각속도, 신경, 근육 상태와 다음 날개 명령은 보존하며 `boundary_corrections`를 증가시킨다. 이는 실제 벽 접촉 행동의 검증된 모델이 아니다.

## 로컬 의존성과 권리

신경 모델에는 사용자가 제공한 로컬 flysim 프로젝트가 필요하다. 공개 저장소에서 자동 설치하는 모델이 아니며, 전체 로컬 코드의 공개 취득 경로와 단일 릴리스 번호는 확인하지 못했다. 현재 입력의 파일별 버전은 공개 검증 요약의 source_sha256과 새 에피소드 해시로 식별한다. `NeuralConfig(source_root=...)`, `--neural-source` 또는 `FLYTRACKER_NEURAL_SOURCE`로 경로를 지정한다. `--neural-data`는 가공 CSV 경로만 바꾼다.

필수 파일은 `flysim/core.py`, `flysim/neural.py`, `flysim/neural_state.py`, `flysim/physics.py`, `flysim/behavior.py`와 `data/stage2/neurons.csv`, `edges.csv`다. 현재 모델은 매 실행에 확장 회로를 사용하므로 `data/raw/Drosophila_brain_model/Connectivity_783.parquet`와 `data/raw/flywire_annotations/supplemental_files/Supplemental_file1_neuron_annotations.tsv`도 필요하다. 기본 NumPy와 Gymnasium 외에 현재 신경 모델에는 PyArrow도 필수다. rule은 이 의존성과 원본 경로 없이 동작한다. 누락된 경로, CSV, 원자료는 오류로 알리고, 원자료와 가공 연결 수, 부호가 다르면 거부한다.

기록에는 실제 경로, 원본 코드, CSV, 원자료 해시, 현재 통합 코드 해시, LIF, 물리, 자극 설정을 저장한다. 원본이나 의존성이 바뀌면 결과가 달라질 수 있다. 해시는 버전을 식별하지만 원본 보관이나 권리 허가를 대신하지 않는다.

로컬 원본의 data/raw/Drosophila_brain_model/LICENSE에서 외부 philshiu/Drosophila_brain_model 코드의 MIT 고지(2023 Philip Shiu 및 Nico Spiller)를 확인했다. PyArrow의 Apache-2.0 배포 메타데이터도 확인했다. 이를 로컬 flysim 전체나 데이터 전체의 허가로 확대하지 않는다. 로컬 코드, 가공 CSV, 정확한 뉴런 주석에 적용되는 재배포 조건은 미확정이며 코드, 원자료를 저장소에 복사하거나 공개하지 않았다. 확인한 출처와 미해결 조건은 [권리 구분](31-feature-neural-flight/rights-status-neuromechanics-20261112.json)에 남긴다.

## 실행법과 기록

저장소 루트의 PowerShell에서 실행한다. 아래 기록 명령은 새 run을 만들며 기존 결과를 덮어쓰지 않는다. 저장 없이 확인하려면 `--no-save`를 붙인다.

```powershell
$env:FLYTRACKER_NEURAL_SOURCE = '<사용자가 확보한 로컬 flysim 프로젝트 경로>'
$env:PYTHONDONTWRITEBYTECODE = '1'

# 무조준 30초: 가상 자극과 포획 없음
.\.venv\Scripts\python.exe -B -m scripts.record_free_flight --no-aim --seconds 30 --seed 0

# 조준 4초, 해제 4초 반복, 포획으로 종료하지 않음
.\.venv\Scripts\python.exe -B -m scripts.record_free_flight --seconds 30 --seed 0

# 기존 관측 기반 조준기와 포획 종료 조건
.\.venv\Scripts\python.exe -B scripts/record_baseline.py --fly-model neural --episodes 1 --seed 0
```

## 검증과 정리

정리 후 전체 회귀는 129개 통과, 건너뜀 0개다. 기존 140개에서 폐기 모델 전용 검사를 제거, 통합하고 현재 모델 검사를 보강했으므로 개수만 비교하지 않는다. 유지한 검사는 rule 수치 회귀, 좌표, 상태, reset 재현성, 분할 실행, 감각, 회로 대조, 접촉, 시간 순서, 실제 저장과 viewer 호환성을 포함한다. 이전 FlightSimulation, MotorDecoder 생성자를 오류로 바꿔도 현재 모델과 기준 발화 계산이 동작하는 검사도 추가했다.

정리 전후 seed 0, 301, 805를 각각 2초 실행해 매 5ms의 위치, 속도, 자세, 각속도, 신경 전압, 지연 큐, 발화 필터, 날개 힘, 토크 해시가 같음을 확인했다. 남긴 run 3개도 전체 길이로 재실행했다. 총 66.08초, 3,307개 프레임의 기존 필드와 활성 진단, 정확한 자극, phase 사건이 일치했다. 제거한 불필요한 진단 키와 코드 해시는 비교 대상에서 제외했다. [공개 검증 요약](31-feature-neural-flight/validation-summary.json)의 replay에 조건과 실행 비용을 기록한다.

### 보존한 반응, 긴 비행 결과

[공개 검증 요약](31-feature-neural-flight/validation-summary.json)의 prior_physics는 이번 정리 전 코드 해시로 측정한 결과다. 현재 코드로 60조건과 240초 전체를 다시 측정한 결과로 표시하지 않는다. 이번 정리의 수치 동일성 근거는 별도의 3개 seed 검사와 남긴 기록 전체 재실행이다.

반응 검사는 seed 801..805에서 각 12조건, 총 60조건이다. 0.3/1/3m와 방위 -90/0/90°의 9조합, 1m 후방 180° 한 조건, 1m 방위 45°, 고도 ±30° 두 조건을 썼다. 평시 1초 후 250ms 자극을 제시하고 총 2초까지 관찰했다. 감각 입력이 생긴 조건과 escape phase가 생긴 조건은 각각 55/60이었다.

운동 반응은 같은 회로와 같은 seed의 무자극 실행과 비교했다. 자극 후 1초 관찰 중 신체 전방 축 방향 차이의 최댓값이 15° 이상인 조건도 55/60이었다. 후방 5조건은 반응하지 않았다.

주 대조 30조건은 5개 seed 각각의 무손상 무자극, DNp06 억제 자극, DNp06+DNp03 억제 자극, 전체 연결 제거 자극, DNg02 억제 무자극, DNa15/DNb01 억제 무자극으로 구성한다. 자극을 주는 세 억제 회로 각각에 같은 회로와 seed의 무자극 실행을 붙여 15조건을 추가했다. DNp06 억제만으로는 5/5조건에서 phase와 운동 반응이 남았다. DNp06+DNp03 억제 시 escape phase는 0/5이나 운동 변화는 2/5 남았고, 전체 연결 제거 시 두 반응 모두 0/5였다. 이 결과는 시험한 회로, 자극 조건의 인과 검사이며 생물학적 회로 전체의 필수성 결론이 아니다.

긴 비행은 seed 0, 801..805를 각각 30초, 806을 60초 실행한 총 240초다. 매 5ms의 48,000개 표본에서 비유한 상태, 방 밖 위치, 잘못된 quaternion, 접촉 보정이 모두 0이었다. 전체 속도 범위는 약 0.108~1.072m/s다. 제한된 조건의 결과를 무제한 안정성 증거로 쓰지 않는다.

[정리 전 비용 기록](31-feature-neural-flight/neuromechanics-benchmark-trim-20261112.json)은 Windows 11, Python 3.12.16, NumPy 2.5.4, Gymnasium 1.4.0, PyArrow 26.0.1에서 seed 701..703 각각 5초, 250행동을 실행한 값이다. 250번 step의 합산 벽시계 비용은 rule 0.040~0.057초, 신경 4.086~4.358초였다. 다른 프로세스 부하는 통제하지 않았고 reset 비용은 별도다. 이번 정리 후 성능 측정으로 바꿔 쓰지 않는다.

실제 행동 참고 집계인 Muijres 등 자료 집계 JSON은 로컬에만 유지하며 재배포 조건 확인 전 공개 대상에서 제외한다. Drosophila hydei의 선택된 92개 기동 기록이며 개체 92마리나 동일 조건 검증 집합을 뜻하지 않는다. 다른 종, 자극, 초기 조건과 섞어 현재 모델이 실제 비행을 재현했다고 판정하지 않는다.

### 삭제 범위와 보존 검사

폐기한 관찰용 운동 모델, 폐기한 dynamics=source 운동 선택 경로, 지속 beam 인코더, 스케줄러와 전용 CLI를 제거했다. 이전 운동 해독기 호출, 미사용 OU 상태, 속도 명령, 벽 가속도 진단과 표시 배율 옵션도 제거했다. 필요한 일반 측정 함수와 외부 행동 자료 검사는 현재 검증 도구와 `tests/test_flight_reference.py`로 옮겼다.

삭제한 전용 파일은 `flytracker/neural_profiles.py`, `scripts/validate_neural_behavior.py`, `scripts/validate_neural_mechanism.py`, `tests/test_inspection_profile.py`, `tests/test_neural_behavior_validation.py`다. 마지막 파일의 유효한 자료 검사는 새 테스트로 옮겼다. Issue #31 부속 자료 중 이전 검사 폴더 8개와 파일 17개도 제거했다. 실패, 폐기 모델을 다시 채택하지 않도록 이유만 이 문서에 남긴다.

삭제한 run은 dynamics=source 운동 2개, inspection-3d 4개, 수정 전 신경 날개 3개로 총 9개, 17에피소드다. 수정 전 신경 날개 중 `2026-11-12_174511_01-30`은 4,871회 경계 보정을 일으킨 실패 기록이었다. 그 실행과 다른 두 중간 실행을 현재 시연으로 사용하지 않는다. 전체 삭제 대상은 39개 경로, 124개 파일이며 모두 Issue #31에서 추가한 것으로 HEAD에 없는 경로만 삭제했다.

삭제 전 확정한 절대 경로가 작업 디렉터리 안에 있고 재분석 지점이 없는지 검사한 후 PowerShell의 `Remove-Item -LiteralPath`로 삭제했다. `runs/index.json`에서도 해당 9개 항목만 제거했다. 기존 main 기능, 원본 프로젝트, 기준선과 사용자가 수정한 `docs/issues/README.md`는 삭제 대상에서 제외했다.

최종 보존 검사에서 기준선의 8개 파일과 남긴 run 3개에 속한 총 9개 파일의 SHA-256, 원본 전체 3,061개 파일의 크기, 수정 시각, 원자료 2개 파일의 SHA-256을 대조해 모두 일치했다. 사용자가 수정한 이슈 목록 `docs/issues/README.md`의 파일 해시도 대조해 일치했다. 결과와 현재 코드 해시는 [공개 검증 요약](31-feature-neural-flight/validation-summary.json)에 남긴다.

## 남은 한계

발화에서 근육, 날개로의 변환, 부분 회로 외부 입력과 초기 기준 설정은 독립 보정이 필요하다. 두 도피 출력 억제 후 남은 운동 변화의 원인 분리, 극단 자세와 장시간 비행, Python 3.10용 선택 의존성 실행, 실제 학습과 재배포 권리는 미완료다.

시선 연동 자극은 정책에 따라 시각과 이후 비행 경로가 달라진다. 같은 seed가 정책 간 같은 궤적을 보장하지 않는다. 무자극과 연동 조건을 분리해 포획, 자극 횟수, 노출과 신경, 운동 반응을 함께 평가해야 한다. 정책과 무관한 고정 자극은 일반 환경 기능으로 구현하지 않았으며 검사 도구의 고정 사건을 그 기능으로 간주하지 않는다.


## 코드 리뷰 공개 준비

공개 대상은 현재 구현과 테스트, 관리 문서, 출처 및 해시, 소규모 검증 집계와 직접 생성한 viewer 캡처다. 상세 실험 궤적, 원본 전체 파일 목록, 외부 행동 집계 JSON, 작성용 대장과 승인 준비 파일은 Git에서 제외한다. 해당 파일은 로컬에 보존하며 원본 프로젝트와 기준선도 바꾸지 않는다. 공개 요약은 제외한 상세 결과의 SHA-256과 측정 당시 코드 해시를 기록한다.

원본 경로를 지정하지 않은 설치에서도 전체 테스트를 실행했다. 84개 통과, 신경 통합 45개 건너뜀으로 끝났으며, 이는 로컬 원본을 지정해 129개가 통과한 검사와 구분한다. 신경 계산을 검토하는 팀원은 별도로 권한을 확보한 원본과 자료를 준비해야 한다. 원본 없이 rule 환경과 일반 계약을 확인할 수 있지만 생물학적 신경 계산 전체를 확인한 것은 아니다.

게시 대상은 개인 Fork의 feature/31-neural-flight에서 Organization의 issue-31로 보내는 PR이다. 공개 준비 시점의 조회에서 두 저장소 ADMIN을 확인했으며 Organization의 issue-31은 없었다. 사용자 승인 뒤 생성 직전에 main을 재확인하고, 브랜치가 여전히 없을 때만 최신 main을 기준으로 생성한다. 기존 issue-31이 생겨 있으면 그대로 사용한다.

Organization main은 관측 시점 64c60ff이며 현재 작업 기준 7237428보다 3개 커밋 앞서 있다. 그 사이 양측 환경 작업으로 env, fly, record, 공통 CLI 등 겹치는 파일이 바뀌었다. 현재 검증은 최신 main과의 통합 검증이 아니며 PR에 충돌 가능성과 통합 미검증을 명시한다. 이번 공개 준비에서 main을 병합하거나 현재 이력을 재작성하지 않는다.

사용자가 검토한 파일 목록과 PR 초안에 대해 커밋, push, 필요한 원격 브랜치 생성과 PR 생성을 승인했다. 승인 범위의 작업 로그를 기록하고 현재 브랜치에 커밋한다. Fork의 같은 브랜치에 일반 push하며 force push는 하지 않는다. PR은 Issue #31을 참조하는 코드 리뷰용으로 생성하고 merge하지 않는다.
