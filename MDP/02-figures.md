# 02 그림 지침

> `02-fly-markov-process.md`에 들어갈 그림 열두 장을 만드는 사람이나 AI에게 주는 지침입니다. 본문을 읽지 않아도 그릴 수 있게 필요한 정의와 값을 모두 적었습니다.

## 1. 요청

그림은 열두 장이고 모두 새로 그립니다. 색, 글꼴, 선 굵기, 범례 형식은 01의 그림을 그대로 물려받습니다. 01의 그림과 01의 스크립트 `figures/make_figures.py`는 고치지 않습니다.

열두 장 가운데 일곱 장은 시간선 그림입니다. 그림의 설명 문장은 본문에 이미 있으므로 그림 안에는 넣지 않습니다.

## 2. 배경

방 안의 한 점 $p_0$에 고정된 카메라가 yaw와 pitch로만 돕니다. 카메라의 방향 $s_{\mathrm{cam}}$에서 화면에 들어오는 방 안의 공간이 $\mathrm{View}(s_{\mathrm{cam}})$입니다. 카메라의 방향 전체 $\mathcal S_{\mathrm{cam}}$은 원통의 옆면입니다.

방 안에 초파리 한 마리가 납니다. 초파리의 위치와 속도의 쌍이 $s_{\mathrm{fly}}$입니다. 초파리가 화면 안에 있는 동안의 state는 쌍 $s=(s_{\mathrm{cam}},s_{\mathrm{fly}})$이고, 화면 밖으로 나간 뒤의 state는 $s_{\mathrm{end}}$입니다. state 전체가 $\mathcal S$입니다.

카메라의 뒤는 하나로 정해집니다. 초파리의 뒤는 여러 갈래로 이어집니다. 지금 $F$ 안에 있을 때 $u$초 뒤에 놓일 수 있는 state 전체가 $T_u(F)$입니다. 지금 $s$에 있을 때 $u$초 뒤에 $F$ 안에 놓일 확률이 $\mathcal P_u(s,F)$입니다.

### 3.2 표기

기호는 아래 표기 그대로 씁니다.

| 기호 | 뜻 |
|---|---|
| $\mathrm{Room}$, $p_0$ | 방, 카메라의 자리 |
| $\mathrm{View}(s_{\mathrm{cam}})$ | 화면에 들어온 방 안의 공간 |
| $s_{\mathrm{cam}}$, $s'_{\mathrm{cam}}$ | 카메라의 방향 |
| $s_{\mathrm{fly}}$ | 초파리의 위치와 속도 |
| $s_{\mathrm{end}}$ | 초파리가 화면 밖으로 나간 뒤의 state |
| $\mathcal S$, $s$, $s'$ | state space, state |
| $F$ | $\mathcal S$의 부분집합 |
| $T_u(F)$ | $F$에서 $u$초 뒤에 놓일 수 있는 state 전체 |
| $\mathcal P_u(s,F)$ | $s$에서 $u$초 뒤 $F$ 안에 놓일 확률 |
| $\mathcal P_{ss'}$ | 교재의 전이 확률 |
| $t$, $u$ | 시간. 단위는 초 |
| $k$ | Example 2의 상수 |

운동 하나하나는 기호로 적지 않습니다.

### 3.4 금지

그림 안에 문장을 쓰지 않고 라벨은 기호나 명사구로 씁니다. 이 지침에 없는 것(policy, 보상, action, 각속도)을 넣지 않습니다. state에서 state로 가는 화살에 이름표를 붙이지 않습니다. 그림자, 그라데이션, 입체 장식을 쓰지 않습니다. 라벨이 도형이나 다른 라벨과 겹치면 지시선을 써서 바깥으로 뺍니다.

## 5. 그림별 지침

### 그림 1. 방과 카메라와 초파리

01의 그림 1을 그리는 코드를 그대로 씁니다. 방향도 같습니다. 여기에 초파리를 더합니다. 카메라의 축 위에서 $p_0$로부터 1.5 떨어진 점에 강조점 색 점을 찍고 "초파리"를 붙입니다. 그 점에서 화면의 오른쪽 방향으로 길이 0.5인 화살을 강조점 색으로 그립니다. 초파리의 속도입니다.

### 그림 2. 하나로 정해지는 그 뒤

시간선 그림이고 높이는 280입니다. 세로선은 가로 300(시각 $t$)과 가로 480(시각 $t+u$)입니다. 과거 둘을 그리고, 만난 뒤는 강조색 선 하나입니다.


### 그림 3. 카메라의 state와 초파리의 state

두 칸이고 시간선 그림이 아닙니다. 왼쪽 칸은 01의 그림 지침 3.5의 펼친 직사각형입니다. $(30^\circ,10^\circ)$에 강조점 색 점을 찍고 $s_{\mathrm{cam}}$을 붙입니다.

오른쪽 칸은 화면을 나타내는 가로 4, 세로 3 비율의 직사각형이고 위에 "화면"을 적습니다. 가운데에서 오른쪽 위로 조금 벗어난 곳에 강조점 색 점을 찍습니다. 그 점에서 왼쪽 아래로 화면 폭의 5분의 1 길이인 화살을 그립니다. 점 옆에 $s_{\mathrm{fly}}$를 붙입니다.

두 칸 아래에 둘을 묶는 중괄호를 그리고 $s=(s_{\mathrm{cam}},s_{\mathrm{fly}})$를 적습니다.

### 그림 4. 화면 밖으로 나간 뒤

01의 그림 2를 그리는 평면도 코드를 씁니다. 방은 가로 $x$, 세로 $y$가 0에서 4인 정사각형이고 $p_0$는 $(2,2)$입니다. 방향은 yaw 30° 하나만 그립니다. $\mathrm{View}$는 yaw 0°와 60° 사이의 부채꼴이 벽에 잘린 모양이고, 강조 바탕으로 칠합니다.

초파리의 경로는 두 구간입니다. 화면 안의 구간은 강조색 굵기 2pt이고, 화면 밖의 구간은 회색 점선입니다. 좌표는 평면의 $(x,y)$입니다.

```
화면 안: (2.6, 3.4)에서 조절점 (3.0, 3.5), (3.3, 3.2)를 거쳐 (3.3, 2.75)까지
화면 밖: (3.3, 2.75)에서 조절점 (3.4, 2.5), (3.2, 2.2)를 거쳐 (2.9, 2.0)까지
```

시작점에 강조색 점을, 나가는 점 $(3.3,2.75)$에 강조점 색 점을 찍습니다. 나가는 점에서 지시선을 방 밖으로 빼서 $s_{\mathrm{end}}$를 붙입니다. 라벨은 $\mathrm{Room}$, $p_0$, $\mathrm{View}(s_{\mathrm{cam}})$입니다. 범례는 강조색 선에 "화면 안의 초파리", 회색 점선에 "화면 밖"입니다.

### 그림 7. state 하나의 확률과 구역의 확률

축 그림이고 높이는 폭의 5분의 2입니다. 가로축은 "빠르기 (m/s)"이고 범위는 0.1에서 0.6이며 눈금은 0.2, 0.3, 0.4, 0.5입니다. 세로축에는 눈금을 두지 않습니다.

### 그림 10. Example 2의 kernel

시간선 그림이고 높이는 300입니다. 세로선은 가로 200(시각 $t$)과 가로 480(시각 $t+u$)입니다.

곧게 난 운동은 (200, 150)에서 (480, 150)까지의 직선이고 강조색 굵기 2pt입니다. 시작점에 강조점 색 점을 찍고 $s$를 붙입니다. 끝점에 강조색 점을 찍고 $s'$과 $e^{-ku}$를 붙입니다.

속도를 새로 뽑은 운동 넷은 직선에서 갈라져 나갑니다. 강조색 굵기 1.2pt, 투명도 0.6입니다.

```
M260 150 C 330 140, 410 95,  480 80
M320 150 C 380 148, 430 118, 480 108
M300 150 C 370 160, 430 190, 480 200
M380 150 C 420 152, 450 172, 480 178
```

문은 둘입니다. 가로 480의 세로 70에서 118까지와 세로 168에서 210까지입니다. 두 문을 묶어 오른쪽에 $1-e^{-ku}$를 적습니다.

화면 밖으로 나간 운동 하나는 회색입니다. (420, 250)에서 끝나고, 끝점에 회색 점을 찍어 $s_{\mathrm{end}}$를 붙입니다.

```
M240 150 C 300 170, 360 235, 420 250
```

범례는 두지 않습니다.

### 그림 12. 간선의 수와 kernel

두 칸이고 시간선 그림이 아닙니다. 왼쪽 칸은 01의 그림 19의 유향그래프를 그리는 코드를 그대로 씁니다. 노드는 북, 동, 남, 서이고 간선은 북에서 동, 동에서 남, 남에서 서, 서에서 북, 그리고 노드마다 자기 자신으로 가는 것입니다. 간선 옆에 수를 적습니다.

| 간선 | 수 | 간선 | 수 |
|---|---|---|---|
| 북에서 동 | 0.7 | 북에서 북 | 0.3 |
| 동에서 남 | 0.6 | 동에서 동 | 0.4 |
| 남에서 서 | 0.5 | 남에서 남 | 0.5 |
| 서에서 북 | 0.8 | 서에서 서 | 0.2 |

오른쪽 칸은 01의 그림 9와 같은 둥근 사각형 하나이고 $\mathcal S$를 붙입니다. 안의 왼쪽에 강조점 색 점을 찍고 $s$를 붙입니다. 안의 오른쪽에 강조 바탕으로 칠한 타원을 그리고 $F$를 붙입니다. 점에서 타원으로 가는 강조색 화살을 하나 그리고 그 위에 $\mathcal P_u(s,F)$를 적습니다.

두 칸 사이에 "간선의 수"와 "kernel"을 양쪽 화살로 이어 적습니다.
